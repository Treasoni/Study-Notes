# 客户A · 自动化清单

> 自动化 = 系统**替你做事**，不用每次手动操作。分四大类，按房间与场景组合。户型图确认后细化为逐房间点位。

## 1. 离家 / 回家模式

| 触发 | 自动执行 |
|------|---------|
| **离家**（出门 / 手动按「离家」） | 全屋关灯 → 窗帘关闭 → 安防布防 → 扫地机器人开始清扫 → 非必要电器断电 |
| **回家**（开门锁 / 进门传感器 / 手动） | 撤防 → 玄关+客厅灯亮 → 空调按季节与习惯预冷/预热 → 播放欢迎语音（可选） |
| **家人先回**（部分人离家状态判断） | 只执行「回家」的安全部分，不打扰已休息区域 |

## 2. 安防联动告警

| 触发 | 自动执行 |
|------|---------|
| 布防状态下门/窗被打开 | 全屋报警声（可选）→ 手机推送告警 → 摄像头开始录像 → 灯光全亮威慑 |
| 有人体出现在布防区域 | 同上，可设置「延迟布防」避免误报 |
| 烟雾 / 燃气浓度异常 | 声光报警 + 手机推送 + 联动开窗（如有） |
| 漏水（阳台/厨房/卫生间） | 手机推送 + 关闭水阀（如安装） |
| 摄像头侦测到人形 | 推送抓拍截图，夜间联动门口灯 |

## 3. 照明场景 + 人体感应

| 场景 | 自动执行 |
|------|---------|
| **人来灯亮、人走灯灭** | 走廊/卫生间/阳台装人体传感器，人来亮灯（夜间低亮度），人走 2 分钟后关灯 |
| **晨间** | 卧室窗帘按日出渐开，亮度缓缓提升 |
| **晚间** | 按日落自动开灯，客厅亮、走廊低亮度夜灯 |
| **阅读/观影** | 一键：客厅主灯关闭，灯带开启，窗帘关闭 |
| **夜起** | 夜间起身，床底/走廊低亮度灯带亮起，不刺眼不吵醒他人 |

## 4. 温控 / 窗帘 / 场景全家桶

| 场景 | 自动执行 |
|------|---------|
| **空调联动** | 温度高于设定 → 自动开空调；离家自动关；回家前预冷 |
| **窗帘定时** | 主卧早晨日出渐开、晚间日落关闭；客厅白天自动收起保持采光 |
| **睡眠模式** | 一键：全屋关灯、窗帘关闭、安防布防、夜灯亮、空调切睡眠曲线 |
| **影音模式** | 降窗帘、关主灯、开投影/电视、灯带进入氛围色 |
| **来客模式** | 全屋亮灯、客厅窗帘开、安防临时撤防 |

## 优先级与默认值

| 自动化 | 默认开关 | 说明 |
|--------|---------|------|
| 离家/回家 | 开 | 门锁为触发源，最稳定 |
| 安防联动 | 开 | 布防状态才触发，避免误报 |
| 照明人体感应 | 开（夜间低亮度） | 可单独关闭某房间 |
| 温控/窗帘 | 开（按季节调整） | 空调曲线每季度微调 |

> [!note] 全部可开关
> 每一条自动化都可以单独开关、单独调参。验收时逐条演示，客户满意才保留；不需要的随时关闭，不影响其他功能。
