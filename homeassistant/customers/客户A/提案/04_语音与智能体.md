# 客户A · 语音与智能体

> 两套「声音入口」各有分工：**小爱音箱**负责日常快指令，**AI 智能体**负责复杂跨品牌指令。互补使用，稳定与智能兼得。

## 1. 为什么分工？

市面上的智能音箱（小爱/天猫精灵/小度）都只能**完整控制自家生态**。要「一句话控制全屋所有品牌」，需要一个能看懂全屋设备的大脑——就是我们的 **AI 智能体**。

| 入口 | 擅长 | 不擅长 |
|------|------|--------|
| **小爱音箱** | 快指令：开灯、关窗帘、调空调、放音乐（小米设备秒响应） | 跨品牌复杂指令、多设备组合 |
| **AI 智能体** | 「我出门了，全屋关灯关窗帘启动扫地机布防」「睡前把主卧调暗、安防布防」 | 无（文本/语音都支持） |

## 2. 小爱音箱

- 放在客厅、主卧等常待区域（按需求 1–3 台）
- 控制**已绑进米家 App** 的设备（含 Aqara、Yeelight、德施曼米家版等）：灯、窗帘、空调、门锁状态
- 响应快、离线也能控米家本地设备
- **边界**：小爱只能控「绑进米家」的设备。非米家品牌（萤石摄像头、美的/格力空调、杜亚窗帘、涂鸦插座、飞利浦 Hue）请用 **AI 智能体**——一句话照样全控

## 3. AI 智能体（核心亮点）

基于 DeepSeek 大模型的**自研智能体**，接入家庭平台后：

- **自然语言理解**：说人话就行，不用记命令词
  - 「客厅灯太亮了」→ 自动调暗
  - 「我出门了」→ 全屋关灯关帘 + 扫地 + 安防布防
  - 「主卧空调 26 度，2 小时后关」→ 精准执行
- **跨品牌调度**：小米/Aqara/杜亚/萤石/美的/格力/海尔/石头/涂鸦/飞利浦 全部统一指挥
- **多设备组合**：一句话同时控制多台设备
- **安全保护**：只允许控制照明/开关/窗帘/空调等安全设备，且操作前校验设备状态；关键操作（如开锁）不开放给智能体

## 4. 使用方式

| 方式 | 说明 |
|------|------|
| 手机 App 聊天 | 打开 App 和智能体打字聊天，就像微信聊天 |
| 网页对话 | 电脑上也能用 |
| 语音（后续可扩展） | 需要更深入语音交互时可接入语音硬件（二期可选） |

## 5. 典型对话示例

| 你说 | 智能体执行 |
|------|-----------|
| 「回家模式」 | 开门锁 → 玄关/客厅灯亮 → 撤防 → 空调按习惯预冷 |
| 「把餐厅灯调到 40%，窗帘打开一半」 | 餐厅灯调暗 + 窗帘开半 |
| 「全屋检查一遍有什么异常」 | 巡检门锁/门窗/摄像头/传感器，汇报异常 |
| 「我睡觉了」 | 全屋关灯 → 窗帘关闭 → 安防布防 → 夜灯亮起 |

## 6. 数据与隐私

- 智能体调用 DeepSeek 云端大模型，仅传输「设备名 + 控制指令」语义，不传输音视频
- 设备状态与录像存在**家里 NAS**，本地为主，不依赖任何厂商云（小米设备走米家云账户，账号由客户持有）
- 摄像头录像只在本地 NAS，不上传公网
