# 客户A · 自动化实现

> 复用笔记场景模板方案（[[ai-smart-home-system/07_场景模板与自动化]]）：packages + Blueprint，`input_boolean`（模式开关）+ `script`（动作序列）+ `automation`（触发器）。多客户复制靠 template 层替换实体。

## 0. 结构

```text
config/
├── packages/
│   ├── away.yaml        # 离家
│   ├── home.yaml        # 回家
│   ├── sleep.yaml       # 睡眠
│   ├── security.yaml    # 安防联动
│   ├── lighting.yaml    # 照明+人体感应
│   └── comfort.yaml     # 温控/窗帘/场景
└── blueprints/automation/{author}/...
```

`configuration.yaml` 启用 packages：

```yaml
homeassistant:
  packages: !include_dir_named packages
```

> ⚠️ packages 文件名（去扩展名）必须是合法 domain：**无连字符、无中文**，否则被静默跳过。中文放 frontmatter/注释，不放文件名。

## 1. 离家/回家/睡眠 三件套（模板）

以「离家」为例（`packages/away.yaml`）。核心套路：`input_boolean` 置位靠**动作序列末尾**，`mode: single` 防重入。

```yaml
# packages/away.yaml
input_boolean:
  away_mode:
    name: 离家模式
    icon: mdi:home-logout

script:
  away_sequence:
    alias: 离家动作序列
    mode: single
    sequence:
      - service: light.turn_off
        target:
          entity_id: "{{ states.light | selectattr('state','eq','on') | map(attribute='entity_id') | list }}"
      - service: cover.close_cover
        target:
          entity_id: "{{ states.cover | selectattr('state','eq','open') | map(attribute='entity_id') | list }}"
      - service: vacuum.start
        target:
          entity_id: vacuum.robot
      - service: alarm_control_panel.alarm_arm_away
        target:
          entity_id: alarm_control_panel.home
      # 最后置位
      - service: input_boolean.turn_on
        target:
          entity_id: input_boolean.away_mode

automation:
  - alias: 离家触发
    trigger:
      - platform: state
        entity_id: lock.entry_main
        to: "locked"
      - platform: state
        entity_id: binary_sensor.entry_door
        to: "off"          # 示例：最后一人离开判断用 person 插件
    condition:
      - condition: state
        entity_id: input_boolean.away_mode
        state: "off"
    action:
      - service: script.away_sequence
```

> [!warning] 幂等
> 所有「全关/全开」类自动化必须 `mode: single` + 动作末尾才置位标志 + 触发前检查标志为 off。避免重复触发造成设备反复开关。

## 2. 安防联动（packages/security.yaml）

```yaml
automation:
  - alias: 布防门窗告警
    trigger:
      - platform: state
        entity_id: binary_sensor.entry_door
        to: "on"
    condition:
      - condition: state
        entity_id: alarm_control_panel.home
        state: armed_away
    action:
      - service: light.turn_on
        target: { entity_id: "{{ states.light | map(attribute='entity_id') | list }}" }
      - service: notify.mobile_app_*      # 推给顾问与家人
        data:
          title: "⚠️ 安防告警"
          message: "入户门被打开"
      - service: camera.snapshot
        target: { entity_id: camera.entry_main }

  - alias: 烟雾/燃气/漏水推送
    trigger:
      - platform: state
        entity_id:
          - binary_sensor.kitchen_smoke
          - binary_sensor.kitchen_gas
          - binary_sensor.bathroom1_leak
        to: "on"
    action:
      - service: notify.mobile_app_*
        data:
          title: "⚠️ 安全告警"
          message: "{{ trigger.to_state.name }} 触发"
```

> 安防告警推给「顾问 + 家人」两个渠道。摄像头联动快照抓拍。

## 3. 照明 + 人体感应（packages/lighting.yaml）

```yaml
automation:
  - alias: 走廊人来灯亮（夜间低亮度）
    trigger:
      - platform: state
        entity_id: binary_sensor.corridor_2f_presence
        to: "on"
    condition:
      - condition: sun
        after: sunset
    action:
      - service: light.turn_on
        target: { entity_id: light.corridor_2f_night }
        data:
          brightness_pct: 20
      - delay: "00:02:00"
      - service: light.turn_off
        target: { entity_id: light.corridor_2f_night }
```

## 4. 温控 / 窗帘（packages/comfort.yaml）

```yaml
automation:
  - alias: 主卧日出渐开窗帘
    trigger:
      - platform: sun
        event: sunrise
        offset: "-00:15:00"
    action:
      - service: cover.set_cover_position
        target: { entity_id: cover.master_bed_curtain_l }
        data: { position: 100 }

  - alias: 温度过高开空调
    trigger:
      - platform: numeric_state
        entity_id: sensor.master_bed_temperature
        above: 27
    condition:
      - condition: state
        entity_id: climate.master_bed_ac
        state: "off"
    action:
      - service: climate.turn_on
        target: { entity_id: climate.master_bed_ac }
      - service: climate.set_temperature
        target: { entity_id: climate.master_bed_ac }
        data: { temperature: 26 }
```

## 5. Blueprint 复用

把「人体感应 + 定时关灯」这类高复用逻辑抽成 Blueprint：

```yaml
# blueprints/automation/{author}/presence_light.yaml
blueprint:
  name: 人体感应灯
  domain: automation
  input:
    presence_sensor:
      selector: { entity: {} }
    light:
      selector: { entity: {} }
    brightness_pct:
      default: 100
      selector: { number: { min: 1, max: 100 } }
    delay_off:
      default: "00:02:00"

trigger:
  - platform: state
    entity_id: !input presence_sensor
    to: "on"
action:
  - service: light.turn_on
    target: { entity_id: !input light }
    data:
      brightness_pct: !input brightness_pct
  - delay: !input delay_off
  - service: light.turn_off
    target: { entity_id: !input light }
```

## 6. 重载 vs 重启

| 变更 | 命令 |
|------|------|
| YAML 场景/自动化 | `automation.reload` / `homeassistant.reload_core_config` |
| custom_components 代码 | 完整重启：`ha core restart` / REST `POST /api/services/homeassistant/restart` |
| Add-on / 镜像 | Supervisor 管理 |

## 7. 多客户模板替换

- 实体名全部走 `entity_map.yaml`（客户唯一文件）
- 构建期用 jinja2 把模板 + entity_map 渲染成客户 packages，校验用 `hass --script check_config`
- 绝不在模板里写死客户实体/密钥
