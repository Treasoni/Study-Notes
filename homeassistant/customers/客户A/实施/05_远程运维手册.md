# 客户A · 远程运维手册

> 全包长期维护的技术底座：**Tailscale 组网 + 三层备份 + 告警通道**。原则：管理面不出公网、数据本地为主、异地兜底。

## 1. Tailscale 组网

> 免费、加密（WireGuard）、秒级接入。所有设备进同一 tailnet，顾问从自己节点访问，**不暴露任何公网端口**。

### 接入节点

| 节点 | 角色 | 安装方式 |
|------|------|---------|
| NAS（绿联 DXP4800 Plus） | 宿主，运行 tailscaled | Docker 容器 `tailscale/tailscale`，`--state=/var/lib/tailscale` |
| HAOS VM | 可选（NAS 已入网则可不装） | Add-on `Tailscale` 或经 NAS 端口转发 |
| 顾问电脑/手机 | 管理端 | 官方客户端登录同一 tailnet |

```bash
# NAS Docker 启动 Tailscale（示例）
docker run -d --name tailscale \
  -v tailscale-state:/var/lib/tailscale \
  -v /dev/net/tun:/dev/net/tun \
  --network host --privileged \
  tailscale/tailscale up --advertise-routes=192.168.x.0/24
```

> 订阅 Tailscale 后台，把 NAS/HA 加进 ACL。顾问通过 `http://<tailscale-ip>:8123` 维护 HA。

### 安全基线

- **绝不**把 NAS 管理端口、HA 8123、米家/DeepSeek 密钥暴露公网
- 关闭 UPnP / 不必要的端口转发；弱电箱贴「勿动」标签
- 客户不需要远程管理权限（顾问代管）

## 2. 备份策略（三层）

### ① HA 快照 → NAS（每周）

- HAOS 内置快照：配置 + Add-on + 自动化
- Supervisor → 设置 → 备份 → 自动备份到 Samba 共享（NAS `ha-backup`）
- 每周自动，保留 4 周轮换

```yaml
# 自动备份 Add-on 或脚本（示例，走 Supervisor API）
# POST /api/hassio/backups/new  （需 HA 主管权限令牌）
```

### ② NAS 数据保护（实时）

- 照片/文件/录像在 NAS，RAID 阵列 + Btrfs/快照（UGOS 按阵列能力启用）
- 硬盘健康定期检查（每月维护项）

### ③ 异地兜底（每周）

- 移动硬盘（`offsite` 共享）每周同步关键数据：HA 快照 + 家庭照片
- 手动或脚本（rsync/cp），同步后盘收好（或加密后放安全处）
- 关键：**NAS 整机损坏也能恢复**（HA 快照 + 照片）

> [!tip] 三份备份
> 设备 1 份 + NAS 内 1 份 + 异地 1 份。任一单点故障可恢复。

## 3. 告警通道

| 通道 | 用途 | 配置 |
|------|------|------|
| HA 通知（手机 App） | 安防/烟雾/漏水告警推给**家人** | HA App 推送，`notify.mobile_app_*` |
| 顾问告警 | 系统异常推给**顾问**（客户无感） | Server酱/PushPlus 或自建 bot → 微信/Telegram |
| 设备离线告警 | 每月维护自动检查 | `device_tracker`/在线传感器 + 告警自动化 |

```yaml
# 顾问告警（示例：关键设备离线）
automation:
  - alias: 关键设备离线告警（顾问）
    trigger:
      - platform: state
        entity_id: sensor.ha_uptime
        to: "unavailable"
    action:
      - service: notify.pushplus   # 或 serverchan
        data:
          title: "⚠️ 客户A 系统异常"
          message: "Home Assistant 离线，请检查"
```

> 原则：**安防/安全告警给客户，系统运维告警给顾问**，客户不被技术噪音打扰。

## 4. 应急预案

| 故障 | 处理 |
|------|------|
| 客户报「App 打不开」 | 顾问 Tailscale 进 HA，查日志；多数是网络/更新问题 |
| NAS 异常 | Tailscale 进 NAS 管理页；必要时引导客户断电重启（弱电箱有标签） |
| HA 更新翻车 | 用快照回滚（备份先行是铁律） |
| 断网 | 本地自动化照跑；语音/远程不可用，恢复后自动重连 |
| 设备离线 | 查电池/掉电/信号；Zigbee 设备检查中枢网关在线 |

## 5. 交接/撤离

- 若客户终止维护合同：移交所有账号（米家/DeepSeek/NAS/HA），撤销 Tailscale 节点，删除客户 `.env`/`entity_map` 中本司密钥引用
- 客户资料（户型图/点位表/账号）只在 `customers/客户A/` 本地保存，gitignore 不入库
