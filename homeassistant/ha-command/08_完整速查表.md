# 第八章：完整速查表（cheat-sheet）

> [!summary] 本章讲什么
> 全书收官：把 `ha` 命令 19 个顶层命令组全量压成速查表——高频 11 组给一行式语法，低频 8 组给全部子命令，附全局 flags 与 `SUPERVISOR_*` 环境变量、常用命令推荐与升级一条龙。日常不翻正文，直接查这一章。

全书收官。这一章把 `ha` 命令的 19 个顶层命令组**全量**压成速查表——正文详述过的高频组压成一行式语法，低频组把全部子命令列出来。日常用不到翻正文，直接查这一章。

## 全局语法与 flags

```bash
ha <group> <command> [args] [flags]
ha <group> --help        # 查看该组全部子命令
ha --help                # 查看全部命令组
```

| Flag | 作用 | 对应环境变量 |
|------|------|-------------|
| `--api-token string` | Supervisor API token（远程必填） | `SUPERVISOR_API_TOKEN` |
| `--endpoint string` | Supervisor 端点（默认 `supervisor`，远程 `http://IP:PORT`） | `SUPERVISOR_ENDPOINT` |
| `--config string` | 配置文件（默认 `$HOME/.homeassistant.yaml`） | — |
| `--log-level string` | 日志级别（默认 WARN） | `SUPERVISOR_LOG_LEVEL` |
| `--no-progress` | 禁用进度动画 | — |
| `--raw-json` | 输出原始 JSON | — |
| `-h/--help` | 帮助 | — |

> [!warning] 环境前提
> `ha` 只在 **HAOS / HA Supervised** 存在；Docker Container / Core 直装没有。Supervised 宿主 shell 无命令时用 `docker exec -it hassio_cli bash`；HAOS 控制台 `HA>` 先 `login`。

## 高频组（一行式语法）

### ha core

| 命令 | 用途 |
|------|------|
| `ha core check` | 校验配置语法 |
| `ha core info [--raw-json]` | 版本/状态 |
| `ha core logs [-f] [--lines N]` | Core 日志 |
| `ha core restart [-s/--safe-mode] [-f/--force]` | 重启（安全模式排障） |
| `ha core start` / `ha core stop` | 启动 / 停止 |
| `ha core stats` | CPU/内存/网络/磁盘统计 |
| `ha core update [--version x.y.z] [--backup]` | 升级 / 降级（别名 upgrade/downgrade） |
| `ha core rebuild` | 重建 Core 容器 |
| `ha core options --boot/--port/--ssl/--watchdog/--duplicate-log-file` | 运行选项 |

### ha supervisor

| 命令 | 用途 |
|------|------|
| `ha supervisor info` | 总览（各组件版本/channel） |
| `ha supervisor logs [-f]` | Supervisor 日志 |
| `ha supervisor reload` | 轻量重载配置 |
| `ha supervisor update [--version]` | 升级（升级顺序第一步） |
| `ha supervisor options [-c/--channel stable\|beta\|dev] [-t/--timezone] [--auto-update]` | 选项 |
| `ha supervisor restart` | 重启 |
| `ha supervisor stats` | 资源统计 |
| `ha supervisor repair` | 修复 |
| `ha supervisor available_updates` | 列出可用更新 |

### ha addons（开发版为 ha apps）

| 命令 | 用途 |
|------|------|
| `ha addons` | 列出已安装 addon |
| `ha addons info [slug] [--raw-json]` | addon 详情（默认 self） |
| `ha addons install <slug>` | 安装（只装最新版） |
| `ha addons uninstall <slug>` | 卸载 |
| `ha addons update <slug> [--version] [--backup]` | 升级（无更新时退出码 1；别名 upgrade/up） |
| `ha addons start/stop/restart <slug>` | 生命周期控制 |
| `ha addons logs <slug> [-f] [--lines N]` | 日志 |
| `ha addons stats <slug>` | 资源统计 |
| `ha addons rebuild <slug>` | 重建容器镜像 |
| `ha addons changelog <slug>` | 更新日志 |

addon slug：官方 `core_*`（`core_ssh`、`core_mosquitto`）；社区 `作者ID_*`（`a0d7b954_adguard`）。获取：addon 详情页 URL `/hassio/addon/<slug>/info` 或 `docker ps` 容器名 `addon_<slug>`。

### ha host

| 命令 | 用途 |
|------|------|
| `ha host reboot` | 重启宿主机（立即执行） |
| `ha host shutdown` | 关机（需手动开机） |
| `ha host info` | 宿主机信息 |
| `ha host options --hostname` | 修改主机名 |
| `ha host logs boots` | 启动日志 |
| `ha host disks usage` | 磁盘使用情况 |

> 旧文档 `ha host update` 已废弃，OS 升级走 `ha os update`。

### ha os

| 命令 | 用途 |
|------|------|
| `ha os update [--version x.y]` | 升级 OS（双槽切换，失败回退） |
| `ha os info` | A/B 双槽版本 |
| `ha os datadisk list` | 数据盘列表 |
| `ha os datadisk move` | 迁移数据盘 |
| `ha os datadisk wipe` | 抹除数据盘（本地终端专用，输入 YES，不可逆） |
| `ha os import` | 从 USB 导入配置 |
| `ha os config swap options --swap-size/--swappiness` | swap 设置 |
| `ha os boot_slot` | 启动槽查看/切换 |
| `ha os boards` | 板卡配置 |

### ha network

| 命令 | 用途 |
|------|------|
| `ha network info` | 网卡 IP/网关/DNS/方法 |
| `ha network update <iface> --ipv4-method static\|auto\|disabled --ipv4-address --ipv4-gateway --ipv4-nameserver --wifi-ssid --wifi-psk --mdns --llmnr` | 改接口配置 |
| `ha network scan` | 扫描 WiFi |
| `ha network reload` | 重载网络配置 |
| `ha network vlan` | VLAN 管理 |

静态 IP 示例：

```bash
ha network update eth0 --ipv4-method static --ipv4-address 192.168.1.100/24 --ipv4-gateway 192.168.1.1 --ipv4-nameserver 8.8.8.8,8.8.4.4
ha network info
```

### ha hardware

| 命令 | 用途 |
|------|------|
| `ha hardware info [--raw-json]` | 系统硬件信息 |
| `ha hardware audio` | 音频设备信息 |

### ha info / ha jobs / ha resolution

| 命令 | 用途 |
|------|------|
| `ha info` | 系统总览（arch/channel/docker/hassos/homeassistant/hostname/machine/supervisor/timezone/supported_arch） |
| `ha jobs info` | 运行中/排队任务 |
| `ha jobs options` | 任务条件管理 |
| `ha jobs reset` | 重置任务队列（清 `done:null` 堆积） |
| `ha resolution info` | Supervisor 问题/建议（checks/issues/suggestions） |
| `ha resolution check run` | 手动健康检查 |
| `ha resolution healthcheck` | 检查项状态 |
| `ha resolution issue dismiss <slug>` | 忽略问题 |
| `ha resolution suggestion apply/dismiss <slug>` | 应用/忽略建议 |

### ha backups

| 命令 | 用途 |
|------|------|
| `ha backups` / `ha backups list` | 列出备份 |
| `ha backups new --name [--password] [-a/--app] [-f/--folders] [-l/--location] [--homeassistant-exclude-database] [--uncompressed]` | 创建备份 |
| `ha backups info <slug>` | 备份详情（区分 full/partial） |
| `ha backups restore <slug> [--password] [--folders] [--app]` | 恢复（partial 必须指定内容） |
| `ha backups remove <slug>` | 删除 |
| `ha backups options --days-until-stale 30` | 过期策略（默认 30 天） |
| `ha backups freeze` / `thaw` | 暂停/解冻备份引擎 |
| `ha backups reload` | 重载备份列表 |

> [!warning] 备份要点
> `--password` 是备份加密密钥非登录密码；全量备份用 `hassio.backup_full`；CLI 无 download，下载走 Web UI。

## 低频组（全部子命令）

| 命令组 | 子命令 |
|--------|--------|
| `ha audio` | `info` / `default` / `volume` / `profile`（音频引擎 hassio_audio） |
| `ha dns` | `info` / `options` / `reset` / `restart` / `update`（内部 DNS hassio_dns） |
| `ha docker` | `info` / `registries add\|delete` / `migrate_storage_driver`（Docker 后端与私有镜像仓库） |
| `ha multicast` | `info` / `update` / `restart` |
| `ha observer` | `info` / `update` |
| `ha cli` | `info` / `update`（`ha` 工具本体升级） |
| `ha banner` | 打印欢迎横幅 |
| `ha auth` | `list` / `reset` / `cache`（`list` 仅本地终端可执行） |

## 开发版新增组

开发版（dev channel）额外提供：`ha mounts`、`ha security`、`ha store`。尚未进入官方 19 组文档，正式使用前以 `ha --help` 实际输出为准。

## 常用命令推荐

日常最值得记住的 10 条：

```bash
ha info                                    # 系统总览
ha core check                              # 改配置后必验
ha core restart --safe-mode                # 排障安全重启
ha core logs -f                            # Core 实时日志
ha supervisor logs -f                      # Supervisor 实时日志
ha addons logs <slug> -f                   # addon 实时日志
ha jobs reset                              # 清卡住任务
ha resolution check run                    # 手动健康检查
ha backups new --name "manual-backup"      # 手动备份
ha network update eth0 --ipv4-method static --ipv4-address 192.168.1.100/24 --ipv4-gateway 192.168.1.1   # 静态 IP
```

升级流程一条龙：

```bash
ha backups new --name "before-upgrade"
ha supervisor update
ha core update --backup
ha os update
```

## 本章小结

- 19 个命令组全量覆盖：高频 11 组给一行式语法，低频 8 组（audio/dns/docker/multicast/observer/cli/banner/auth）给全部子命令。
- 全局 flags 与 `SUPERVISOR_*` 环境变量一张表速查，远程调用靠 `--endpoint` + `--api-token`。
- 开发版新增 `mounts` / `security` / `store` 三组，以 `ha --help` 实际输出为准。
- 所有不确定的命令，一律 `ha <组> --help` 校验后再执行。
