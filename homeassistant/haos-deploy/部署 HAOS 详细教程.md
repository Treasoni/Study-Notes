# 部署 HAOS 详细教程：国内源 + 稳定运行

> [!summary] 全文摘要
> 本文是一篇面向国内网络环境的 [[01_绪论|HAOS]] 专项部署实操教程，聚焦「怎么装、怎么配国内源、怎么稳定运行」三件事。全篇 8 章沿「安装 → 加速 → 对比 → 稳定 → 排障」主线展开：先备齐平台、存储、固件、镜像与工具链，再走通官方原版 HAOS 在实体机、VMware、PVE、群晖 VMM 四大平台的完整安装；随后为官方原版手动配置一套国内加速（Docker 12 源故障转移、Supervisor ghcr 镜像、Add-on 国内仓库、NTP 国内时间源），并介绍内置全套加速的一键替代方案 [[05_HAOS-CN极速版|HAOS-CN]] 极速版；最后用双路线对比表完成选型，落定 SSD 迁移、Google Drive 世代备份、升级回滚等稳定运行策略，以及错误码速查与长期运维清单。文中所有镜像站地址、版本号、错误码均以实际官网/日志为准，素材采集时间 2026-08-06。

## 学习路径

本教程是一条完整主线：安装 → 加速 → 对比 → 稳定 → 排障。第 1 章建立「官方原版 + 手动国内源 vs HAOS-CN 极速版」的双路线心智模型；第 2 章备齐平台、存储、固件、镜像与工具链；第 3 章走通官方原版在实体机、VMware、PVE、群晖 VMM 四大平台的安装；第 4 章为官方原版手动配置 Docker / Supervisor / Add-on / NTP 国内源；第 5 章介绍内置全套加速的一键替代方案 HAOS-CN 极速版；第 6 章用对比表锁定选型；第 7 章落定 SSD 迁移、Google Drive 世代备份与升级回滚；第 8 章提供错误码速查与每周/每月长期运维清单。

本文与 [[Home Assistant 三种部署方式对比与选型]] 分工明确：选型笔记回答「HAOS / Docker Container / Supervised 该选哪个」（Supervised 已于 2025.12 弃用）；本文默认你已选定 HAOS，只聚焦「怎么装 + 国内源 + 稳定运行」，不重复选型对比。
