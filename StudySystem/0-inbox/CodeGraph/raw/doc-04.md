最近 GitHub Trending 上冲上来一个叫 CodeGraph 的项目，直接登顶。它的定位很有意思——给你用的 AI 编程助手装一个"本地代码导航仪"。 同期还有好几个类似项目在撞赛道，尤其是 GitNexus 和 Graphify，跟它的定位最接近。 本期视频聊聊这三者的核心差异： CodeGraph：纯 MCP server，让 AI agent 少在代码仓库里瞎翻 GitNexus：有 CLI+MCP 也有 Web 可视化，能做变更风险分析 Graphify：多模态知识图谱，代码+文档+图片+视频全整合 AI 编程的下半场，不再是模型能力的竞争，而是"AI 理解代码的能力"的竞争。
