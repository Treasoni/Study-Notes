# LangGraph Multi-Agent Workflows (Blog Post)

**URL**: https://www.langchain.com/blog/langgraph

## Multi-Agent Future Work

LangGraph multi-agent workflows are mentioned as a feature, with the LangChain team being "incredibly excited about the possibility of LangGraph enabling more custom and powerful agent runtimes" and listing multi-agent workflows among the features they're looking to implement.

## Core Value

The post emphasizes that LangGraph's core value lies in enabling **cyclical graphs** for agent runtimes, with the ability to create state machines via graph specifications using nodes, edges, and state management.

## Related Content

A separate blog post titled "From Token Streams to Agent Streams" contains additional details about multi-agent approaches and streaming for agent workflows.
