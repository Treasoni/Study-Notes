# LangGraph GitHub README Overview

**URL**: https://github.com/langchain-ai/langgraph

## Core Description

LangGraph is a low-level orchestration framework for building, managing, and deploying long-running, stateful agents.

**Trusted by companies shaping the future of agents** – including Klarna, Replit, Elastic, and more.

## Key Features

- **Durable execution** — Persists through failures, automatically resuming from where it left off
- **Human-in-the-loop** — Incorporate human oversight by inspecting and modifying agent state
- **Comprehensive memory** — Short-term working memory and long-term persistent memory across sessions
- **Debugging with LangSmith** — Visualize execution paths and state transitions
- **Production-ready deployment** — Scalable infrastructure for stateful, long-running workflows

## Ecosystem Guidance

For quickly building agents, consider **Deep Agents** — a higher-level package built on LangGraph for agents that can plan, use subagents, and leverage file systems for complex tasks.
