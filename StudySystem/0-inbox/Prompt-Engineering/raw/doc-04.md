# 设计提示的通用技巧

## 从简单开始

提示设计是一个迭代过程：
1. 先用简单提示开始
2. 逐步添加元素和上下文
3. 将复杂任务分解为简单子任务
4. 逐步构建

## 使用清晰指令

用动词明确指示任务：
- "写入"
- "分类"
- "总结"
- "翻译"
- "解释"

将指令放在开头，并用分隔符（如 `###`）分隔指令和上下文。

## 保持具体性

提示越具描述性和详细，结果越好：
- 提供示例能有效获得特定格式的输出
- 明确期望的输出格式
- 指定长度限制

但避免包含不相关的细节。

## 避免不明确

过于聪明或模糊的描述反而有害：
- 像有效沟通一样，越直接，信息传达越有效
- 明确指出风格、长度和受众
- 避免歧义性表达

## 说什么该做，不说什么不该做

明确告诉模型应该做什么，比告诉它不要做什么更有效。

例如：
- ✅ "使用2-3句话向高中学生解释"
- ❌ "保持简短，不要过于描述"

## 核心原则总结

1. **从简单开始，迭代优化**
2. **具体且描述性**
3. **直接明确，避免歧义**
4. **正面表述任务目标**
