# 零样本 vs 少样本提示

- **Source**: https://www.promptingguide.ai/zh/techniques/fewshot
- **Author**: dair-ai
- **Date**: 持续更新
- **Type**: official

---

## Zero-shot（零样本提示）

指模型在不依赖任何示例的情况下，仅凭预训练知识执行任务的能力。

模型能够根据其训练数据中学习到的模式来理解和执行指令，无需额外的示例。

## Few-shot（少样本提示）

在提示中提供示例演示，引导模型获得更好的表现。研究表明，以下条件时效果最佳：

- 标签空间和输入文本分布定义明确
- 示例格式一致（即使标签是随机排列的）
- 标签来自真实分布，而非均匀分布

### 示例

```
"farduddle" 的意思是快速上下跳动。用它造句："我们都开始庆祝并 farduddling。"
```

### 局限性

少样本提示对复杂推理任务（需要多个步骤）效果有限。当少样本失败时，需要更高级的技术如链式思考提示。

## 何时选择

- **零样本**：任务简单、模型能力足够强
- **少样本**：需要特定格式输出、需要模型学习特定模式
