# GPT-4 核心特点

- **Source**: https://www.promptingguide.ai/zh/models/gpt-4
- **Author**: dair-ai
- **Date**: 持续更新
- **Type**: official

---

## 能力表现

- **多模态**：支持图像和文本输入，输出文本
- **专业测试**：在各类基准测试中达到人类水平
- **律师考试**：模拟考试中位列前10%
- **可靠性**：比GPT-3.5更可靠、更有创意
- **跨语言**：跨语言性能显著提升

## 提示词设置

- 通过`system`消息引导模型以特定语气和风格回答
- 支持少样本提示和链式思考（CoT）技术
- "请逐步推理"等指令可引导模型进行渐进式解释
- 温度参数可调整（如设为0.5以获得更有信心的答案）

## 与GPT-3.5主要差异

- 更强的视觉能力
- RLHF训练后TruthfulQA基准测试准确性更高
- 更好的事实性、可控性和对齐性
- 系统消息引导效果更持久有效
