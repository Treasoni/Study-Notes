## 各平台详解

### Coze（扣子）—— 字节跳动出品
- 上手最快（15分钟搭建可用客服Agent）
- 800+ 插件市场、可视化工作流、多模态支持
- 仅支持单Agent，不支持私有化部署
- 总分：40.5/50

### Dify —— 开源界的一面旗帜
- 核心能力最全面：RAG引擎、ReAct/Function Call/Multi-Agent、20+模型供应商
- 可视化DAG工作流、自动生成REST API
- 社区版免费，企业版付费（SSO、审计日志等）
- 总分：43/50（排名第一）

### 阿里百炼
- 通义千问全系列模型、预制行业模板
- 强绑定阿里云生态
- 总分：37.5/50

### 百度千帆
- 中文语义理解领先、知识库管理全
- 产品线过多易混淆
- 总分：37/50

### Microsoft Copilot Studio
- 深度集成Microsoft Graph、Power Automate
- 每个Agent每月200美元，价格昂贵
- 总分：37/50

### LangGraph
- 核心能力最强（StateGraph、多Agent编排、人工审核）
- 学习曲线陡峭，无可视化界面
- 总分：40/50

## 选型决策树

**Q1：你有没有技术团队？**
- 没有 → Coze
- 有，但不想自己维护 → Dify云端版或百炼/千帆
- 有，想完全掌控 → Dify私有化或LangGraph

**Q2：数据能不能上公有云？**
- 可以 → 随便选
- 必须私有化 → Dify（唯一开源可私有化成熟选项）

**Q3：在哪个云/生态上？**
- 阿里云 → 百炼；百度云 → 千帆；Microsoft 365 → Copilot Studio；不绑定 → Dify或LangGraph
