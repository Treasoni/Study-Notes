# WorkMate：开源企业级AI智能体平台

> 来源：科技日报
> URL: https://www.stdaily.com/web/gdxw/2026-06/24/content_536558.html
> 作者：杨雪
> 日期：2026年6月24日

## 概述

2026年6月22日，中央财经大学与兆企供应链联合开源发布 **WorkMate**，定位为"企业级超级AI工作伙伴"，强调可控、可审计、可进化。

## 背景

Gartner预测2026年底"全球40%的企业应用将嵌入具备任务执行能力的AI智能体"。但多数企业仍停留在"买了AI账号"到"真正用起来"的鸿沟中。

## 核心范式：Harness Engineering（驾驭工程）

核心理念是给AI"戴上方向盘、装上刹车和后视镜"，实现三层控制：
- 环境隔离
- 策略规则
- 人工审批

## 开源内容

| 组件 | 说明 |
|------|------|
| Harness Framework | 核心"驾驭工程"框架 |
| 10个供应链基础Skills模板 | 覆盖报价、合同、风控、数据分析 |
| MCP SDK | Model Context Protocol开发工具包 |

## 落地效果数据

| 流程 | 之前 | 之后 |
|------|------|------|
| 塑化贸易报价回复 | ~20分钟 | 30秒 |
| 行业报告撰写 | ~4小时 | 15分钟 |
| 合同审批 | ~1天 | 20分钟 |

## 目标行业

首期聚焦塑化/石化行业（年交易额超2万亿元，覆盖30万+上下游企业）
未来计划扩展至有色金属、农产品等领域

## 治理与审计

- 权限同源（permission homology）
- 全链路审计机制
- 让财务人员"从核算型转向价值创造型"

## 战略意义

中央财经大学表示，WorkMate将为国内产业提供"一个安全、低成本、可信赖的AI智能体底座"，加速全行业数智化转型。
