# 实战示例

## 1. 少样本提示示例

**场景**: 学习新词用法

```
"farduddle" 的意思是快速上下跳动。用它造句："我们都开始庆祝并 farduddling。"
```

**要点**: 
- 提供词义定义
- 包含完整示例
- 模型可直接学习格式

**来源**: doc-02

---

## 2. 链式思考示例

**场景**: 判断奇数和是否为偶数

```
这组数字中奇数的和是偶数：4, 8, 9, 15, 12, 2, 1。
A：所有奇数（9, 15, 1）相加等于 25。答案是：False。
```

**要点**:
- 展示完整推理过程
- 分解为中间步骤
- 模型学习推理模式

**来源**: doc-03

---

## 3. Zero-shot CoT 示例

**场景**: 复杂推理任务

```
问题：小明有5个苹果，小红给了他3个，小明吃掉了2个，小明还剩多少个？
让我们一步一步思考。
```

**要点**:
- 添加"让我们一步一步思考"
- 无需提供示例
- 激活模型推理能力

**来源**: doc-03

---

## 4. 清晰指令示例

**场景**: 信息提取

```
从以下文本中提取所有的人名和对应职位：
###文本内容###
[文本内容...]
###结束###
```

**要点**:
- 用分隔符`###`分隔指令和内容
- 明确指出要提取的信息类型
- 结构化便于模型理解

**来源**: doc-04

---

## 5. 正面表述 vs 负面表述

**❌ 负面表述（效果差）**:
> "保持简短，不要过于描述，避免使用专业术语"

**✅ 正面表述（效果好）**:
> "使用2-3句话向高中学生解释"

**要点**: 明确告诉模型应该做什么

**来源**: doc-04
