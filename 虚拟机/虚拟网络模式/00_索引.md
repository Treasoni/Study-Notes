## 核心脉络

```
1998 ─── VLAN (802.1Q) ────── 4094 个网络，二层隔离
  │
2014 ─── VXLAN ────────────── 1600 万网络，Overlay 架构
  │
2010s ── SDN ──────────────── 转控分离，可编程网络
  │
2015+ ── 云原生 (CNI/eBPF) ── 容器原生，内核级处理
```

> [!summary] 一句话总结
> 从 **物理硬隔离**（VLAN）到 **虚拟软定义**（VXLAN/SDN），再到 **云原生可插拔**（CNI/eBPF）——每一代技术都在解决上一代的局限。
