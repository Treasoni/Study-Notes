# VMware 获取虚拟机所有权失败

## 问题描述

VMware Workstation 启动虚拟机时弹窗报错：

- **"获取该虚拟机的所有权失败"**
- **"主机上的某个应用程序正在使用该虚拟机"**

## 原因分析

这是一个非常经典的 VMware 虚拟机报错，通常由以下情况触发：

- 虚拟机异常关闭
- 宿主机突然断电重启
- VMware 软件崩溃

VMware 在运行虚拟机时会生成 **锁文件（.lck）** 防止数据损坏。如果非正常关闭，锁文件没有被自动删除，下次启动时 VMware 会认为虚拟机仍在运行，从而拒绝访问。

## 解决步骤

### 步骤 1：取消弹窗

在报错弹窗上点击 **"取消"**，不要强行启动。

### 步骤 2：进入虚拟机目录

打开资源管理器，进入虚拟机存放路径（根据报错提示）：

```
D:\vmware file\window 11\
```

### 步骤 3：删除 .lck 锁文件

在文件夹中找到以 **.lck** 结尾的文件或文件夹，例如：

- `Windows 11 x64.vmx.lck`
- `Windows 11 x64.vmdk.lck`

将所有 `.lck` 文件/文件夹**全部删除**。

> [!tip] 安全提示
> 这些 `.lck` 只是临时锁定标记，删除不会损坏虚拟机系统或数据。

### 步骤 4：重新启动虚拟机

删除完毕后，回到 VMware Workstation，再次启动虚拟机。

## 补充：无法删除 .lck 文件

> [!warning] 文件被占用
> 如果 Windows 提示 **"文件被占用无法删除"**，说明后台有残留的 VMware 进程。

1. 按 `Ctrl + Shift + Esc` 打开任务管理器
2. 在"详细信息"中找到 **vmware-vmx.exe** 进程
3. 右键 → **结束任务**
4. 再回去删除 `.lck` 文件夹即可
