# 无线网络信息

## 从有线到无线：多了什么

有线网络的信息查询核心在接口、IP、路由——这些概念在无线环境下依然存在，但无线多了两个关键维度：**信号质量**和**AP 关联状态**。前者决定了你能不能连上、连上了快不快；后者决定了你连的是哪个 AP。

本章聚焦无线特有的信息查询，包括 `iw` 命令族、旧版 `iwconfig` 的等效操作，以及 `nmcli` 的无线管理功能。

> [!note] 前置说明
> 本章命令需要**无线网卡**支持。如果你当前设备只有有线网卡（如大部分服务器），可以通读了解命令结构，实操部分跳过。多数命令需要 `root` 权限或 `sudo`。

---

## 1. iw vs iwconfig：新旧工具链

Linux 无线工具也经历了类似 `iproute2` vs `net-tools` 的更替。

| 对比维度 | `iw`（现代） | `iwconfig`（旧版） |
|---------|-------------|-------------------|
| **所属包** | `iw` | `wireless-tools` |
| **内核接口** | nl80211（netlink） | Wireless Extensions（ioctl） |
| **支持新硬件** | 全面支持 802.11n/ac/ax | 部分新特性不支持 |
| **维护状态** | 活跃维护 | 2009 年后基本停滞 |
| **输出格式** | 结构化，可脚本解析 | 纯文本，无标准格式 |
| **预装情况** | 多数现代发行版预装 | 需 `apt install wireless-tools` |

### 命令等效替换

| 查询目标 | `iwconfig` 旧命令 | `iw` 新命令 |
|---------|------------------|------------|
| 列出无线网卡 | `iwconfig` | `iw dev` |
| 查看连接状态 | `iwconfig wlan0` | `iw dev wlan0 link` |
| 扫描 AP | `iwlist wlan0 scan` | `iw dev wlan0 scan` |
| 查看频率/信道 | `iwconfig wlan0` | `iw dev wlan0 info` |
| 查看监管区域 | — | `iw reg get` |

> [!tip] 推荐策略
> 和 `iproute2` 一样，**优先使用 `iw`**。只有维护老旧系统时才需要用 `wireless-tools`。

## 2. `iw dev`：查看无线网卡

最基本的操作用 `iw dev` 列出系统上的无线网卡：

```bash
# 列出所有无线网卡
sudo iw dev
```

**预期输出**：

```
phy#0
	Interface wlan0
		ifindex 3
		wdev 0x1
		addr  a4:5e:60:xx:xx:xx
		type managed
		channel 6 (2437 MHz), width: 20 MHz, center1: 2437 MHz
```

**输出解读**：

| 字段 | 含义 |
|------|------|
| `phy#0` | 物理无线设备编号（一个物理设备可以在不同 phy 上） |
| `Interface wlan0` | 网络接口名称 |
| `addr` | 无线网卡 MAC 地址 |
| `type managed` | 工作模式（managed=客户端，AP=热点，monitor=监听） |
| `channel / width` | 当前使用的信道和带宽 |

对比 `ip link show` 的输出——`ip link` 只能看到接口的 UP/DOWN 状态和 MAC 地址，而 `iw dev` 额外显示了无线专属信息（信道、模式、带宽），这些是有线查询工具看不到的。

## 3. `iw dev wlan0 link`：查看当前连接状态

这是无线排查最常用的命令——**不需要扫描，只输出当前关联的 AP 信息**。

```bash
# 查看当前连接的 AP 状态
iw dev wlan0 link
```

**预期输出**（已连接状态）：

```
Connected to 12:34:56:78:9a:bc (on wlan0)
	SSID: MyHomeWiFi
	freq: 5180
	RX: 433.3 MBit/s
	TX: 200.0 MBit/s
	signal: -45 dBm
	tx bitrate: 200.0 MBit/s MCS 5 80MHz short GI
	bss flags:	short-preamble short-slot-time
	dtim period:	2
	beacon int:	100
```

**未连接状态**：

```
Not connected.
```

### 关键指标解读

| 指标 | 示例值 | 解读 |
|------|--------|------|
| `SSID` | MyHomeWiFi | 当前连接的 AP 名称 |
| `freq` | 5180 | 频率（MHz），5180=5GHz，2437=2.4GHz |
| `signal` | -45 dBm | 信号强度，**绝对值越小越强**（详情见后文） |
| `RX` | 433.3 MBit/s | 最大理论接收速率（取决于 MCS/信道宽度） |
| `tx bitrate` | 200.0 MBit/s | 当前实际发送速率 |
| `MCS 5` | — | 调制编码方案索引，越高越快 |
| `80MHz` | — | 信道绑定宽度 |
| `short GI` | — | 短保护间隔（比标准 800ns 短，略微提升速率） |

> [!warning] RX/TX 速率 ≠ 实际吞吐量
> `iw link` 显示的 RX/TX 是**物理层速率**（PHY rate），受信号质量、MCS、信道宽度等因素影响。实际 TCP/UDP 吞吐量受协议开销、干扰、重传等因素影响，通常只有物理速率的 50%-70%。

### 实用脚本：持续监控信号强度

```bash
watch -n 2 "iw dev wlan0 link | grep -E 'signal|SSID|bitrate'"
```

```bash
# 或者用简化版，只看信号
while true; do
  iw dev wlan0 link | grep signal | awk '{print $2, $3}'
  sleep 1
done
```

**预期输出**（每 1 秒更新）：

```
-45 dBm
-47 dBm
-44 dBm
-52 dBm   # 走到信号差的位置，强度下降
```

## 4. `iw dev wlan0 scan`：扫描 AP

要查看周围有哪些无线网络可用，可以使用扫描功能。

```bash
# 扫描周围 AP（需要 root）
sudo iw dev wlan0 scan
```

这个命令输出非常详细，每个 AP 的信息块很长。更实用的方式是用 grep 过滤关键字段：

```bash
# 只看 SSID、信号强度、频率、加密方式
sudo iw dev wlan0 scan | grep -E 'SSID|signal|freq|WPA|RSN'
```

**预期输出**：

```
freq: 2437
signal: -41.00 dBm
SSID: Guest_Network
freq: 5180
signal: -50.00 dBm
SSID: Office_5G
RSN:	* Version: 1
freq: 2462
signal: -72.00 dBm
SSID: CRT-WiFi-5G  # 名字带 5G 实际在 2.4GHz，注意区分
```

### 扫描进阶格式化

```bash
# 更结构化的输出：每行显示关键信息
sudo iw dev wlan0 scan | awk -F': ' '
/^BSS /{bss=$2}
/SSID:/{ssid=$2}
/signal:/{signal=$2}
/freq:/{freq=$2" MHz"}
/Channel:/{channel=$2}
/WPA:/{encrypt="WPA"}
/RSN:/{encrypt="WPA2/WPA3"}
bss && ssid {printf "%-20s %-10s %-8s %-10s %s\n", ssid, signal, freq, channel, encrypt; bss=""; ssid=""; encrypt=""}
'
```

**预期输出格式**：

```
Office_5G           -50.00   5180 MHz  6        WPA2/WPA3
Guest_Network       -41.00   2437 MHz  6        WPA2/WPA3
CRT-WiFi-5G         -72.00   2462 MHz  11       WPA2/WPA3
```

### 注意事项

- `iw scan` 需要 root 权限，因为扫描涉及信道切换
- 扫描期间当前连接会短暂中断（几十毫秒）
- 如果扫描返回空结果，先确认无线网卡是否启用：`ip link set wlan0 up`
- 自动扫描由 `NetworkManager` 等工具在后台定期执行，不需要手动反复扫描

## 5. `nmcli device wifi`：用 NetworkManager 管理无线连接

如果你用 NetworkManager 管理网络，`nmcli` 提供了更高级的无线管理功能，比 `iw` 更贴近日常使用场景。

### 5.1 扫描并列出 WiFi 网络

```bash
# 扫描并显示可用 WiFi（不需要 root）
nmcli device wifi list
```

**预期输出**：

```
IN-USE  BSSID              SSID            MODE   CHAN  RATE        SIGNAL  BARS  SECURITY
*       12:34:56:78:9a:bc   MyHomeWiFi      Infra  6     195 Mbit/s  75      ▂▄▆_  WPA2
        98:76:54:32:10:fe   Office_5G       Infra  36    540 Mbit/s  80      ▂▄▆█  WPA3
        00:11:22:33:44:55   Guest_Network   Infra  1     130 Mbit/s  50      ▂▄__  WPA2
```

**输出字段说明**：

| 字段 | 含义 |
|------|------|
| `IN-USE` | `*` 表示当前已连接 |
| `BSSID` | AP 的 MAC 地址 |
| `SSID` | 网络名称 |
| `CHAN` | 信道号 |
| `RATE` | 最大速率（物理层） |
| `SIGNAL` | 信号强度百分比（0-100） |
| `BARS` | 信号格数 ASCII 表示 |
| `SECURITY` | 加密类型（无密码/ WPA/ WPA2/ WPA3） |

> [!tip] `nmcli` vs `iw` 选择建议
> - **快速查看可用网络**：`nmcli device wifi list`（更简洁，自带信号格数）
> - **深度排查信号质量**：`iw dev wlan0 link`（精确到 dBm，含 TX/RX 明细）
> - **底层扫描数据**：`iw dev wlan0 scan`（完整 AP 信息块，适合脚本解析）

### 5.2 连接 WiFi

```bash
# 连接一个开放式 WiFi
nmcli device wifi connect "Guest_Network"

# 连接一个加密 WiFi
nmcli device wifi connect "Office_5G" password "your-password"
```

**预期输出**：

```
Device 'wlan0' successfully activated with 'a1b2c3d4-...'
```

**连接后查看状态**：

```bash
nmcli connection show --active | grep wifi

# 或者更详细
nmcli -f GENERAL,WIFI-PROPERTIES device show wlan0
```

### 5.3 手动触发重新扫描

```bash
# 强制 NetworkManager 重新扫描（无输出，成功即静默）
nmcli device wifi rescan
```

之后再执行 `nmcli device wifi list` 就会显示最新扫描结果。

### 5.4 断开和切换

```bash
# 断开当前 WiFi 连接
nmcli device disconnect wlan0

# 重新连接已保存的网络
nmcli connection up MyHomeWiFi

# 删除已保存的网络配置
nmcli connection delete MyHomeWiFi
```

## 6. 无线信号质量指标解读

### 6.1 dBm 信号强度

这是最核心的无线指标。`iw` 显示的是实际的 dBm（分贝毫瓦）值，`nmcli` 将其映射为 0-100 百分比。

**dBm 参考表**：

| dBm 范围 | 质量评级 | 典型场景 |
|---------|---------|---------|
| `-30` ~ `-50` | 极好 | 路由器旁边，满格信号 |
| `-50` ~ `-60` | 良好 | 同一房间，稳定连接 |
| `-60` ~ `-70` | 一般 | 隔一堵墙，可能偶有波动 |
| `-70` ~ `-80` | 较差 | 隔多堵墙，速率下降明显 |
| `-80` ~ `-90` | 很差 | 信号边缘，频繁掉包 |
| `< -90` | 不可用 | 基本无法连接 |

> [!warning] dBm 是负数，绝对值越小信号越强
> `-45 dBm` 比 `-75 dBm` 信号好。常见误解是看到负数就以为信号差——实际上 `-40` 是非常好的信号。

### 6.2 SIGNAL % vs dBm（nmcli 的转换）

`nmcli device wifi` 显示的 `SIGNAL` 是 0-100 的百分比，来自 dBm 的映射关系：

```python
# nmcli 的换算逻辑大致如下
# -30 dBm → 100%
# -90 dBm → 0%
# 线性映射
signal_pct = min(100, max(0, (-90 - dBm) / (-90 + 30) * 100))
```

也就是说 `-60 dBm` 对应约 50% 的信号格数。但百分比只能反映大致信号级别，精细排查还是要看原值 dBm。

### 6.3 SNR（信噪比）

dBm 信号强度不直接反映**信号质量**。如果环境噪声很大，即使 dBm 看起来不差，实际体验也可能很差。

真正的质量指标是 **SNR = 信号强度 (dBm) - 噪声底噪 (dBm)**。虽然 `iw link` 不一定直接显示噪声值，但可以通过 `iw dev wlan0 survey` 查看：

```bash
sudo iw dev wlan0 survey | grep -A5 "in use"
```

### 6.4 速率 vs 实际性能

`iw link` 显示的 `tx bitrate` 是物理层速率，实际可用 TCP 吞吐量还受到以下因素影响：

| 因素 | 影响 |
|------|------|
| 协议开销 | TCP/IP 头部、WiFi 帧头、ACK 帧等，约损失 20-30% |
| 重传 | 信号差时误码率高，重传进一步降低有效吞吐 |
| 同频干扰 | 附近其他 AP 或设备在同一信道竞争 |
| 客户端能力 | 双天线（2x2 MIMO）比单天线快一倍 |

**一个经验公式**：

```
实际 TCP 吞吐量 ≈ PHY 速率 × 0.5 ~ 0.7
```

例如 `iw` 显示 `tx bitrate: 433.3 MBit/s`，实际下载速度大约在 200-300 Mbps 之间。如果信号差到触发大量重传，这个比例可能降到 0.2 以下。

### 6.5 `nmcli` 查看连接质量

```bash
nmcli device wifi list

# 查看当前连接的详细无线参数
nmcli -f GENERAL,WIFI-PROPERTIES device show wlan0
```

**预期输出**：

```
GENERAL.DEVICE:                         wlan0
GENERAL.TYPE:                           wifi
GENERAL.STATE:                          100 (connected)
...
WIFI-PROPERTIES.BSSID:                  12:34:56:78:9a:bc
WIFI-PROPERTIES.FREQ:                   2437 MHz
WIFI-PROPERTIES.CHAN:                   6
WIFI-PROPERTIES.MODE:                   Infra
WIFI-PROPERTIES.SIGNAL:                 75
```

这里的 `SIGNAL` 就是 0-100 的百分比，75 表示信号较好。

## 本章小结

- **`iw` 是现代 Linux 无线查询标准工具**，通过 nl80211 与内核交互，替代了旧的 `wireless-tools` 系列
- **`iw dev` 查看无线网卡**，`iw dev wlan0 link` 查看当前连接状态（SSID、信号强度 dBm、TX/RX 速率）
- **`iw dev wlan0 scan` 扫描周围 AP**，用 `grep -E 'SSID|signal|freq'` 过滤关键字段可读性更好
- **`nmcli device wifi` 提供更高级的无线路**，`list` 扫描、`connect` 连接、`rescan` 强制刷新，且不需要 root
- **信号强度以 dBm 衡量**，值在 -30 到 -90 之间，数字越小（负的绝对值越大）越接近无信号
- **PHY 速率 ≈ 实际吞吐量 × 1.5~2 倍**，不要误解 `iw` 显示的 bitrate 就是实际网速

> [!tip] 三句话记住本章
> - 查无线：`iw dev` → `iw dev wlan0 link` → `iw dev wlan0 scan`
> - 管连接：`nmcli device wifi list` → `nmcli device wifi connect`
> - 看信号：dBm 越小越强，-50 算优，-75 算差
