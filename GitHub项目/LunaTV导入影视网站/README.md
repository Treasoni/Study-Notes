## 学习路径说明

### 前置要求

- 已在本机部署并启动 lunatv（能打开 Web UI）；本笔记不覆盖从零部署
- 能操作浏览器访问管理后台（`/admin`）
- 基本了解 JSON 结构（手动加源时会用到）
- 可选：会看 docker-compose / 环境变量（第四章排错用到）

### 学完能做什么

- 判断任意一个影视网站能否接入 lunatv（苹果 CMS V10 接口验证）
- 用订阅 URL 一键导入现成影视源，也能手动添加单个站
- 定位并解决导入后的常见问题（配置不生效、源失效、刮削失败、部署环境问题）
- 用 CORSAPI 中转被墙影视站，扩展网盘 / Emby / IPTV 等更多内容源

### 建议学习顺序

- **第一章**快速通读（约 20 分钟）：建立源机制概念，为实操打底
- **第二章 + 第三章**为核心实操（约 40–60 分钟）：照着走一遍「找到站 → 导入 → 能播放」
- **第四章**排错建议边做边查：遇到问题再回来对号入座
- **第五章**进阶可选：跑通基础后按需学习
