# 本地文件系统
_文件系统_ 使应用程序能够在存储设备上存储和检索文件。 文件放置在分层结构中。 文件系统指定文件的命名约定，以及指定树结构中文件路径的格式。
每个文件系统由一个或多个驱动程序和动态链接库组成，这些库定义文件系统的数据格式和功能。 文件系统可以存在于许多不同类型的存储设备上，包括硬盘、jukebox、可移动光盘、磁带备份单元和内存卡。
Windows 支持的所有文件系统具有以下存储组件：
  * **卷** - _卷_ 是目录和文件的集合。
  * **目录** _- 目录是_ 目录和文件的分层集合。
  * **文件** - _文件_ 是相关数据的逻辑分组。


## 在本部分中
以下主题提供有关 Windows 支持的文件系统的信息，包括如何管理文件、目录和卷：  
| 主题  | 描述  |  
| --- | --- |  
|  _目录_ 是目录和文件的分层集合。 单个目录中可包含的文件数的唯一约束是目录所在的磁盘的物理大小。  |  
|  _硬盘_ 是计算机内部的一个刚性磁盘，用于存储和提供对大量数据相对快速的访问。 它是最常用于 Windows 的存储类型。 系统还支持可移动媒体。  |  
|  _文件对象_ 提供可由 I/O 系统管理的资源（物理设备或位于物理设备上的资源）的表示形式。  |  
| 事务 NTFS（TxF）允许在事务中对 NTFS 文件系统卷执行文件作。  |  
| 文件系统中组织的最高级别是 _卷_ 。 文件系统驻留在卷上。  |
