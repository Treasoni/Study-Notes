## 第五章 总结与速查

前四章各讲一块：文件系统、注册表、PowerShell，以及把三者串起来的那套命令。这一章不再引入新内容，只做两件事——把全书出现过的命令收成三张可随时回查的表，再把最容易记反、最容易踩坑的地方集中钉一遍。

还有一个更重要的目的：**把"哪些说法有官方依据、哪些只是"官方未说明"、哪些干脆没写"单独列出来**。前四章是一路铺垫着写的，散落在各处的提醒读者很难一次看全；这一章把它们摊在一页上，方便你在动手前先确认一句"这条到底靠不靠得住"。

> [!note] 本章没有代码块
> 下面是索引，不是教程。所有命令块的完整形式、参数说明和示例输出，都在它标注的"所在小节"里；本章只在表格里给出命令本身和它的三元组（环境 / 版本 / 权限）。**表内命令全部来自前四章正文，没有新增任何一条。**

> "备份"那一行有两个版本：**按键级**是 `reg export` 出的 `.reg`（只保住了你导出的那一个键）；**整机级**是备份"系统状态"。**把"导出了 `HKLM\Software` 下的某个键"当成"备份了整个注册表"，是本笔记反复警告过的误解**，详见 5.2.2。

### 5.2 九个跨方向易错点回顾

这九条是素材在三个方向之间对比时发现的**口径冲突**：社区流传的说法和官方原文不一致，或者两份官方资料本身就不一致。它们不是"冷知识"，而是**照着错的做会出事**的地方。

| # | 易错点（常见错误认知） | 正确口径 | 详见 |
|---|---|---|---|
| 5.2.1 | 以为**系统还原**是注册表回滚的标准做法 | 回滚**主路径 = 导出 `.reg` → 需要时导入还原**（官方覆盖 Win11）；系统还原**只作整机级兜底**，且官方那页的版本声明明显滞后（正文说仅 Win7/Vista/XP 受支持，另一页覆盖 Win11 却完全不提它） | 第 2 章 2.7.6 |
| 5.2.2 | 把"导出 `HKLM\Software` 下的一个键"当成"**备份了整个注册表**" | **按键级备份** = 导出 `.reg`（只保住导出的那个键）；**整机级备份** = 备份"系统状态"（保住整台机器）。**动哪个键，就先导出哪个键** | 第 2 章 2.7.5 |
| 5.2.3 | 以为 `NTUSER.DAT` 有一个可以照抄的**磁盘路径** | 两份官方资料给的路径**不一致**（`%SystemRoot%\System32\Config` vs `%SystemRoot%\Profiles\Username`），而且**都没提现代布局**。本笔记只用"用户配置文件目录"表述，**不写死路径** | 第 2 章 2.3.4 |
| 5.2.4 | 以为 **`Program Files (x86)` 一定存在** | 它**只存在于 64 位系统**；32 位系统上 `FOLDERID_ProgramFiles` 与 `FOLDERID_ProgramFilesX86` 指向**同一个路径**。官方同页对该默认路径的表述前后不一致，本笔记只采用"64 位系统上为 `Program Files (x86)`"这一结论 | 第 1 章 1.4.4 |
| 5.2.5 | 把 `mklink /j` 叫成"**目录硬链接**" | 官方参数表的定义是"**目录联接**"（junction）。硬链接**根本不能指向目录**，所以"目录硬链接"这个说法在概念上就站不住 | 第 1 章 1.6.2 |
| 5.2.6 | 以为有 `mklink /F` 这个参数 | 官方参数表里只有 `/d`、`/h`、`/j`、`/?` 四种。`/F` 是网上的错误信息，敲下去只会得到"参数无效" | 第 1 章 1.6.2 |
| 5.2.7 | 把**执行策略**当成一种"安全设置"，甚至为了"更安全"调到最严 | 官方明说**它不是安全边界**，而是**防误运行的便利机制**——直接在命令行粘贴脚本内容就能绕过。所以：别为了"看起来安全"调到最严，也别因为它"不是安全"就随手关掉 | 第 3 章 3.6.1 |
| 5.2.8 | 想找一个"**改一个设置就好**"的编码开关 | **不存在"5.1 的默认编码"这句话**。编码是**三条独立通道**：① 脚本源码编码 ② `-Encoding` 参数与各 cmdlet 默认值 ③ 控制台与对外部程序编码。哪条漏了修哪条——5.1 里同一个版本不同 cmdlet 写出的编码本身就各不相同 | 第 3 章 3.7.3 |
| 5.2.9 | 以为"安全的做法"是 `AllSigned`，`RemoteSigned` 只是折中 | **默认与推荐都是 `RemoteSigned`**；`AllSigned` 只作为一种"可选更严档位"。另外 **`Undefined` 不等于"没有限制"**——各级作用域都是 `Undefined` 时，客户端上的实际效果是 `Restricted` | 第 3 章 3.6.4 |

### 5.4 接着往下练的建议

这张笔记里的命令，看完不等于会。剩下三件事，按顺序做一遍，基本就稳了。

#### 5.4.1 在自建目录与自建键上练，不碰系统关键键

- **文件系统侧**：在 `C:\Test` 这类自己建的目录里练 `dir` / `attrib` / `icacls` / `robocopy`，不要拿 `C:\Windows`、`Program Files` 做实验（1.4.3、1.9.2）。
- **注册表侧**：所有**修改**类示例都应落在你自己建的键上——本笔记用的是 `HKCU:\Software\Demo` 和 `HKCU:\Software\DemoApp`（4.3.3、4.5.1）。"系统关键键"包括但不限于 `HKLM\SYSTEM`、`HKLM\SAM`、`HKLM\SOFTWARE\Microsoft` 下的各类路径，以及四个开机自启键 [S19]。
- 第二章 2.7.1 引的那句官方警告——错误修改"**可能需要重新安装操作系统才能解决。Microsoft 不能保证可以解决这些问题**" [S6]——是这段纪律的全部理由。

#### 5.4.2 改注册表前先导出 `.reg`，练成条件反射

这一条要在**动手之前就完成**，而不是出事之后再想：

1. 先 `reg export "<要改的键>" <文件名>.reg /y`（或走 regedit「文件」>「导出」）——这是官方覆盖范围最广的一条主路径，覆盖 Windows 11 [S18]；
2. 再 `Get-ItemProperty` 读一次现状；
3. 才动手改（写数字时显式 `-Type DWord` / `QWord`）；
4. 改完 `Get-ItemProperty` 复核一次；
5. 需要回滚时 `reg import <文件名>.reg`。

这套流程的完整版在 4.3.7 与 4.5.2，三个入口（regedit / reg.exe / PowerShell）的对照在 4.5.3。**记住那个分工：PowerShell 负责"改"，`reg.exe` 负责"保命"**——PowerShell 侧没有官方文档化的"导出注册表"cmdlet [S13][S14]。

#### 5.4.3 用 `Get-Help` / `Get-Command` / `Get-Member` 自己探索，不依赖记忆

本笔记只能覆盖到你最可能用到的那一批命令；剩下的靠这三个命令自己挖出来，顺序是官方的推荐顺序 [C-2][C-6]：

1. **`Get-Command`** —— "有没有这条命令？"（配 `-Verb` / `-Noun` 过滤更快）；
2. **`Get-Help`** —— "它怎么用、参数是什么？"（帮助文件没装时先 `Update-Help`，注意 3.4.4 的两条硬限制）；
3. **`Get-Member`** —— "它返回的东西有哪些属性和方法？"（这是对象管道最省事的地方，3.1）。

再加一条：不记得自己在哪个版本里，先敲 `$PSVersionTable`（3.3.3）——本笔记的四项版本差异（默认编码、配置文件路径、`PSModulePath`、`Update-Help` 权限）和 `cd -` / `cd +`，全都拴在 5.1 与 7 的差别上（3.8.5）。

### 本章小结

> [!summary] 小结
> - **三张速查表**：文件系统命令表保留"环境 / 版本 / 权限"三元组 [A5]–[A21]；注册表命令表按 **regedit / reg.exe / PowerShell 三列对照** [S9]–[S21]；PowerShell 命令表分**探索 / 帮助 / 执行策略 / 编码**四组 [C-1]–[C-15]。**表内命令全部来自前四章，无新增**
> - **九个跨方向易错点**：系统还原不是回滚主路径、按键级 ≠ 整机级备份、HKCU 磁盘位置官方两说、`Program Files (x86)` 只存在于 64 位、`mklink /j` 是"目录联接"、`mklink /F` 不存在、执行策略不是安全边界、编码是三条独立通道、默认是 `RemoteSigned` 而非 `AllSigned`
> - **绝大多数"要不要管理员"官方都没写**：全笔记里只有 `diskpart` [A15]、`fsutil` [A18]、regedit 导出/导入 [S18] 三处有明说的提权要求，加 `HKCU\Software\Classes` [S25] 与 `-Scope CurrentUser` [C-3] 两处免提权依据；其余一律"官方未说明"
> - **两类留白要分清**：**"官方未说明"**（官方没写，不等于不用）与**"素材未覆盖所以本笔记不写"**（连现象都没有，如中文用户名 `PSModulePath`、`USRCLASS.DAT`、`RegBack`、`HKCR\*\shell`）；这两类都**不要当成结论使用**
> - **动手三纪律**：在自建目录与自建键上练、改注册表前先导出 `.reg`、用 `Get-Command` → `Get-Help` → `Get-Member` 自己探索

从"数据放在哪"，到"系统和程序怎么配置自己"，再到"怎么用命令批量操作前两者"——这份笔记想留下的不是那几百条命令，而是三样东西：**一套看路径和看键的眼光、一套"先备份再动手"的肌肉记忆、以及一条"这条说法有没有官方依据"的检查习惯**。前面那些表格和清单，都是为这三样东西服务的。

祝你在自己的机器上玩得安心。
