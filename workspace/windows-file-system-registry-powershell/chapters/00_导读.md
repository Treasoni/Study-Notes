## 第零章 导读：文件系统、注册表、PowerShell 是什么关系

装系统、修电脑、写脚本时，你迟早会同时遇到这三个词。它们看起来像三个互不相干的软件，实际上是一套系统的三个层次。这一章不讲命令，只帮你把三者的位置摆正——位置摆正了，后面三章的内容才不会互相打架。

### 0.1 三句话定位：各管一件事

**文件系统**管"数据放在哪"。官方定义里，Windows 支持的所有文件系统共用三个存储组件：**卷**是"目录和文件的集合"，**目录**是"目录和文件的分层集合"，**文件**是"相关数据的逻辑分组" [A1]。你平时双击进文件夹、复制粘贴、看 C 盘还剩多少空间，都是在和文件系统打交道。

> [!tip] 大白话
> 把文件系统想成一个仓库：卷是一整栋库房，目录是一排排货架，文件是货架上的箱子。它只回答"东西在哪个位置、怎么找到"。

**注册表**管"系统和程序怎么配置自己"。它是一个分层数据库，数据以树状组织，树上的每个节点叫**键**，键里可以放**子项**和**值**；官方把这种"键、子项和值"的逻辑组称为**配置单元**，英文 hive [S2]。系统的启动设置、程序的偏好、文件类型的关联方式，都记在这里。

> [!tip] 大白话
> 把注册表想成整台电脑的"后台登记本"：开机要看哪几页、某个程序要什么参数，翻这本本子就能查到。它不存你的照片和文档，只存"怎么设置"。

**PowerShell** 管"怎么用命令批量操作前两者"。它有一套叫**提供程序（Provider）**的机制，把不同的数据存储都以**驱动器**的形式暴露出来，路径与使用方式跟硬盘一样；于是同一批命令可以直接作用在文件上，也能作用在注册表键上 [C-5]。

> [!tip] 大白话
> PowerShell 像一只万能遥控器：不管对面是文件系统这台"电视"，还是注册表这台"空调"，都用同一套按键去操作。

### 0.2 两个交叉点：注册表长在文件系统上

第一个交叉点是**注册表存在硬盘文件里**。官方把配置单元（hive）描述为"一组在操作系统启动时或用户登录时加载到内存中的支持文件"；这些支持文件**大部分**位于 `%SystemRoot%\System32\Config` 目录中，当前用户的配置单元则是 `Ntuser.dat` [S2]。所以注册表和文件系统是"内容"与"存放位置"的关系。

> [!warning] 最容易混淆的一点
> 三者不是三个并列的软件，而是 **存储层（文件系统）/ 配置层（注册表）/ 操作层（PowerShell）** 的关系。读者最常搞错的，就是"注册表也是存在硬盘上的文件"这件事——很多人以为注册表是系统内部某种"内存里的设置"，其实它有实实在在的磁盘文件，只是平时不让你直接编辑。

第二个交叉点是**PowerShell 用同一套命令操作两者**。因为 Provider 把注册表也变成了"盘符"，你在文件系统上用惯的命令，换个注册表路径就能读、能建 [C-5]。这就是本笔记把 PowerShell 排在两个主题章之后的原因：它是把前面的内容串起来的那根线。

### 0.3 本笔记的两个阅读约定

**约定一：每个命令块都带"环境 / 版本 / 权限"三元组。**

- **环境**：这条命令在哪里敲——`cmd`（命令提示符）/ `PowerShell` / `regedit`（注册表编辑器界面）/ `diskpart`（交互式子环境）
- **版本**：`5.1`（`powershell.exe`）/ `7`（`pwsh.exe`）/ `5.1 & 7`；非 PowerShell 命令标"全版本适用"
- **权限**：是否需要管理员

**约定二：官方没写的，一律标"官方未说明"，不替你推断。**

最后一条尤其要注意。比如创建符号链接是否需要提升权限，官方页面根本没提，我们只会如实写"可能需要提升权限，官方文档未明确说明"，而不会编一个"必须用管理员"的结论。

### 0.4 动手前的安全纪律

1. **先在小范围试。** 任何命令先在测试目录、测试键上跑通，再放到正式位置。
2. **改注册表前先导出 `.reg`。** 官方在 reg 命令页用 Caution 级警告写明：注册表编辑器"绕过标准安全措施，允许降低性能、损坏系统甚至要求重新安装 Windows 的设置"，并明确要求"如果必须直接编辑注册表，请先备份它" [S8]。导出备份与导入还原的完整步骤，第 2 章会逐步给出。

### 本章小结

> [!summary] 小结
> - 文件系统管"数据放在哪"，核心结构是卷 / 目录 / 文件三层 [A1]
> - 注册表管"系统和程序怎么配置自己"，由键、子项、值组成 [S2]
> - PowerShell 管"怎么用命令批量操作前两者"，靠 Provider 把一切统一成"盘符" [C-5]
> - 注册表也长在硬盘上：配置单元的支持文件存放在 `%SystemRoot%\System32\Config` [S2]
> - 命令一律标注"环境 / 版本 / 权限"；官方未说明的权限要求写成"官方未说明"
> - 改注册表前先导出 `.reg` 备份，官方对此有 Caution 级警告 [S8]
