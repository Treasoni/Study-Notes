title: "Do Snapshots Retain the IP Address of the Vultr Compute Instance They Were Created From? | Vultr Docs"
scraped_at: 2026-09-23T16:16:09+00:00
---

No, snapshots do not retain the IP address of the Vultr Compute instance they were created from.
IP addresses are automatically assigned to instances using DHCP at the time of provisioning. When you restore a snapshot, a new IP address is assigned unless you [attach a Reserved IP](https://docs.vultr.com/products/network/reserved-ips/management/attachment) to the instance. [Reserved IPs](https://docs.vultr.com/products/network/reserved-ips/provisioning) allow you to retain a consistent public IP and reassign it across instances in the same region, making them ideal for preserving IP continuity during instance rebuilds or migrations.
