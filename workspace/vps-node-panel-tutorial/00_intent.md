## 研究计划

### 探索方向
1. 概念层：VPS / 协议（VMess、VLESS、Trojan、Shadowsocks）/ 面板（3x-ui 等）/ 机场，以及自建 vs 机场的取舍
2. 落地层：VPS 选购 → SSH 登录 → 面板安装 → 建节点 → 带域名 → 客户端使用
3. 运维层：节点被墙的判定与恢复、安全事项与最小加固

### 重点收集
- **核心概念**: VPS、节点、机场、协议族、面板、TLS/SNI、CDN 前置
- **实战步骤**: 选购与付款、SSH 首次登录、面板安装与放行端口、建节点、绑定域名、客户端导入订阅/分享链接、连通性自检
- **常见坑**: 端口未放行、证书/域名解析未生效、面板默认路径与弱口令、节点被墙的识别与 IP 更换、误买机房/线路
- **工具链**: 3x-ui / Xray-core、FinalShell、域名与 DNS、Cloudflare、客户端（Clash/Mihomo、sing-box、Shadowrocket 等）
- **安全事项**: 面板端口与路径、强口令、SSH 加固、不裸奔的边界说明
