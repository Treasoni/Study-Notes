## 全文定位

面向"有网络/软路由基础、但 VPS 选购与节点搭建完全零基础"的读者，以视频章节顺序为骨架、以 `02_deep_research.md` 的来源为唯一事实依据，走完"买 VPS → 登录 → 装面板 → 建节点 → 带域名 → 客户端使用 → 被墙处置 → 最小加固"的完整链路。

读完的产出是：一台可用的 VPS、一个能连通的节点、一份客户端导入方式，以及一套面板默认凭据以外的安全收尾动作。

本篇是"面板流"：所有节点搭建通过 3x-ui 的 Web 界面点选完成，不涉及手写内核配置。

与既有笔记 `自建代理节点/自建代理节点搭建实战.md` 的分工边界：内核直配（手写 Xray JSON）、REALITY 原理、nftables/suricata 深度加固只做指引与双链，不重复展开；本篇补齐既有笔记未覆盖的"带域名搭建"与"节点被墙与换 IP"两块。

篇幅配比按用户确认执行：概念 25%（第 1–2 章，约 2900 字）／落地 50%（第 3–8 章，约 5750 字）／运维 25%（第 9–10 章 + 附录，约 2900 字），总计约 11550 中文字。
