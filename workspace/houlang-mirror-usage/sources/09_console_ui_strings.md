## 本文件回答了哪些缺口

- **G-B 已关闭**：确认控制台确有 **「访问令牌」/「用量」/「镜像源」** 三个分区名，与大 S1（官方教程说「在『访问令牌』选项卡中新建令牌」）一致。
- **D1 的裁决入口被确认存在**：控制台确有一个 **镜像源** 分区（文案称「镜像渠道」），因此「后缀以控制台镜像源列表为准」这句话是**可执行的指引**，不是空话。
- **§3.6 配额节有据可依**：字段名 `月度配额` / `配额窗口` / `不限速` 均得到界面文案佐证；**但仍然没有任何数值**。

## 仍未解决

- 各分区的**默认选中项、字段具体呈现形式**（进度条 / 百分比 / 剩余字节）仍未知——文案只给了标题与开关，没给数值格式。
- 「宽限已过期」这个字符串出现在 bundle 中（疑似配额宽限期概念），**归属页面未确认**，**不要写进笔记**。
