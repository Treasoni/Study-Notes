## 学习路径说明

### 前置要求

- 会用 Docker 基本命令（`docker pull` / `docker login` / `docker images`），不需要从"什么是 Docker"讲起
- 知道什么是镜像仓库与镜像地址（`<registry>/<namespace>/<image>:<tag>` 的构成）
- 有一个能跑 Docker 的目标机器（本地 Docker Desktop 或远程服务器）
- 若要看第 3 章 k8s 部分：了解 containerd 是容器运行时，见过 Pod manifest 的 `image` 字段
- 建议先读 vault 内 `docker/镜像加速器vs代理-概念对比.md` 建立背景（注意：该笔记的"镜像加速器"定义在 2026 年已不完整，本篇的第 1 章是它的修正版）

### 学完能做什么

- 能独立完成"注册 → 建令牌 → `docker login` → 改地址 → `docker pull`"全链路，并判断成功与否
- 遇到任意镜像地址（Docker Hub / GHCR / quay / nvcr / k8s 等）能**查表替换**为厚浪地址
