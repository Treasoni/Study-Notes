## 本次真正新增的知识点（不是只改称呼）

1. 小雅单容器**必须有阿里云盘账号**（三件套必填），但**会员只影响速度**——不付费即限速，甚至实测 SVIP 仍 380kb/s。
2. 夸克在小雅配置里是 `QUARK_COOKIE`（**非必填**），属「额外挂载」，**不能替代**阿里云盘三件套；论坛同问帖未给出「只填夸克」的正面回答。
3. 「302 依赖网盘」是本质而非缺陷：它替掉的是本地硬盘，替不掉网盘；关键是**让片源待在你**有会员**的那个盘上**（社区「阿里转存 115」即此思路）。
4. 替代链路：**把片源搬到夸克**——夸克网盘 TV 驱动 → SmartStrm 生成 STRM → fntv-proxy 302 → 飞牛影视；fntv-proxy 主要面向的正是夸克网盘。
5. 夸克专属坑：部分片源夸克只给 **HLS 转码流**，飞牛/Emby 取不到时长/码率/分辨率；代理只做 302，不转 mp4、不补元数据 → 用 TMDB 外部刮削。
