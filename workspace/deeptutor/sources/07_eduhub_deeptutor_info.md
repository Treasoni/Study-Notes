# Overview
EduHub is an open registry of teaching skills that speaks the ClawHub protocol — package teaching ability as skills and drop them into any agent.
## What is EduHub
A “skill” is a package containing a SKILL.md — a capability playbook for an agent, plus optional support files. Any skill-capable agent that reads it learns how to explain, drill, grade, and mentor.
Search and install are fully open and need no login; only publishing requires a sign-in (to attribute contributors and protect slug ownership).
## Two ways to use
EduHub is both a standalone registry and built into DeepTutor natively. Pick the one that matches your tooling:
  * Any agent (Claude Code, Codex…) — use the eduhub CLI.
  * DeepTutor users — built in already, just deeptutor skills install <slug>.
