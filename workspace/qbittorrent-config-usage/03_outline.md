## 这本册子讲什么

上级分册只把 qBittorrent 当**前提条件**列出（版本下限、`/downloads` 映射、完成回调），却没教怎么装、怎么配、怎么排错——本册补的正是这个缺口。按「**是什么 → 装起来 → 配好 → 用起来**」四步走：先讲清 qBittorrent 在家庭影院里站哪个位置、它和市面上的「增强版」是两个不同项目；再给出 fnOS + Docker 下三选一的镜像对比与可照抄的 compose；然后把端口、下载目录与硬链接、分类限速、完成回调这几处最容易配错的地方一次讲透；最后落到日常使用与排错——加种、Tracker、DHT/PeX/LPD、私种分享率，以及「下不动」时按官方顺序自查。全文采用入门优先档：每章结论先行、先打比方再上术语、代码集中后置并标「新手可跳过」，并把 PT 站阈值、DHT 定义等**无一手来源**之处明确标注为通用机制，绝不编造具体数值。
