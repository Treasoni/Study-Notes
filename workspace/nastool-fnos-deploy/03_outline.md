# 大纲：在飞牛 fnOS 上搭建 nastool 家庭影院（MoviePilot V3 + 不依赖 PT 的备选路）

> 笔记类型：实战笔记（跟着做就能搭起来）｜深度：入门优先 · 照做即用

> 结构规矩：最多三级；命令 / Compose / 配置文件一律收进「动手实践」型小节并标注「新手可跳过」；同一产物的字段收进该产物所在章，不升格为平级章
> 上游素材：`02_deep_research.md`（来源 ID 与断言编号 #1–#38 均取自该文件）

## 一句话看懂

原版 nastool 已归档，现在的主线是同一作者重做的 **MoviePilot V3**（一个把「搜片—下载—整理—刮削—播放」串起来的自动化中枢）；但它的**搜片、订阅、下载必须先过 PT 站点认证**——没有 PT 账号就走不通这几步，只能用它「整理刮削」那一半。所以这篇给你两条路：**主路 A** 照做搭通 MoviePilot V3 完整链路（需要 PT 账号的步骤会提前标出来），**备选路 C** 用不依赖 PT 的网盘流媒体方案，保证你没账号也能立刻有一条能跑通的路。
