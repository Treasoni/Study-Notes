### 第一章：Ventoy 是什么——先搞懂原理再动手
- **篇幅**：中（约 800–1000 字）
- **覆盖要点**：一次性烧录 vs 即拷即用、双分区结构、引导原理、支持平台与镜像格式、与 Rufus/balenaEtcher 对比、适用场景
- **素材引用**：S1、S2、S3
- **代码示例**：无（分区布局示意 + 工具对比表）
- **小节构成**：
  - 传统烧录工具的痛点：刻一个镜像重烧一次；Ventoy 的定位是「装一次引导器，之后拷文件」
  - 核心原理：Ventoy 是引导管理器而非烧录工具，启动时动态扫描镜像并生成启动菜单
  - 磁盘分区结构：分区 1 = 镜像数据区（默认 exFAT，可改 FAT32/NTFS 等）；分区 2 = 32MB VTOYEFI EFI 引导分区；另有 1MB MBR 间隙存放 Legacy 启动文件——放一张「文字版分区示意图」
  - 为什么 EFI 引导分区放第二位：UEFI 规范要求 EFI 分区为 FAT，早期 Windows 只挂载第一分区，放第二可防止用户误格式化引导区
  - 能引导什么：x86 Legacy BIOS、IA32/x86_64/ARM64/MIPS64EL UEFI；镜像支持 ISO/WIM/VHD(x)/EFI
  - 关键认知：启动模式（Legacy/UEFI）由主板决定，Ventoy 不能自行切换；启动菜单左下角模式标识的含义
  - 与 Rufus / balenaEtcher 的取舍（对比表）：何时用 Ventoy（多镜像/常更新/装机维修盘），何时仍用传统烧录（单镜像/特殊兼容需求）
  - 适用场景小结：多系统装机、系统维修 PE 盘、随身工具盘

- **小节构成**：

### 第四章：Linux 制作——命令行参数一次讲清

  - 下载解压 `linux.tar.gz`，**必须 `cd` 到解压目录再执行**（S1/S6）

### 第五章：日常使用与升级——把 U 盘用顺手
- **篇幅**：中（约 800–1000 字）
- **覆盖要点**：镜像增删即文件复制、递归搜索与菜单排序、当普通 U 盘用、Ventoy 安全升级、数据分区文件系统选择、扫描卡顿与 `.ventoyignore`
- **素材引用**：S1、S2、S3
- **代码示例**：有（Linux 升级命令、`.ventoyignore` 示例、可选格式化命令）
- **小节构成**：
  - 增删镜像 = 复制/删除文件：支持 ISO/WIM/IMG/VHD(x)/EFI，直接拷入数据分区任意目录即可
  - 菜单与目录规则：Ventoy 默认递归搜索分区 1 全部子目录并按字母序显示；说明大目录管理的直观后果
  - 兼作普通 U 盘：镜像分区剩余空间可随意存文件，不影响 Ventoy 功能
  - Ventoy 本体升级：Windows「升级」按钮 / Linux `-u`；只覆盖引导分区，镜像不丢、文件系统不被改回 exFAT（区分「升级」与「重装」，避免误操作）
  - 数据分区文件系统选择：普通 U 盘建议 exFAT；大容量移动硬盘/SSD 建议 NTFS；XFS/Ext 系仅纯 Linux 环境可见
  - 镜像很多导致启动扫描卡顿：用搜索路径配置限定范围，或在该目录放 `.ventoyignore` 让 Ventoy 跳过——`.ventoyignore` 用法示例放这里（与第六章扫描卡顿条互相链接）

### 第六章：常见问题与排错——启动不了怎么办
- **篇幅**：中（约 1000–1300 字）
- **覆盖要点**：Secure Boot key 注册流程与失败处置、启动失败分层排查、安装失败进程占用、扫描卡顿、VTOYEFI 分区损坏恢复、Legacy 128GB 限制、模式标识判读
- **素材引用**：S3、S4
- **代码示例**：有（Secure Boot 注册步骤清单、diskpart/diskgenius 修复步骤清单）
- **小节构成**：
  - 排查思路总览：按「引导模式 → 引导分区 → 镜像完整性 → 机器限制」分层定位（表格式决策链）
  - Secure Boot 首次引导：BIOS 开启 Secure Boot 时首次启动出现蓝色 key 注册界面——注册步骤放此处（每台机器仅一次）；出现错误界面（如 Linpus lite）说明方案不兼容，需在 BIOS 关闭 Secure Boot
  - Secure Boot 版本坑：Ventoy 1.1.13+ 因 UEFI CA 2023 需重新注册 key；部分机器需在固件开启 `Allow Microsoft 3rd Party UEFI CA`
  - 启动进 grub shell / 启动失败：排查扩容盘/假盘、老主板 Legacy BIOS 访问范围限制（约 128GB）、镜像损坏（用 checksum 验证）
  - 安装失败：进程占用导致（Paragon ExtFS、DokanMounter、ext2fsd、DiskGenius、Intel DSA 等）——关闭相关软件后重试的步骤
  - 卡在 `Ventoy scanning files, please wait...`：文件过多 → 搜索路径配置 / `.ventoyignore`（回指第五章）
  - VTOYEFI 引导分区损坏无法启动：用 diskgenius/diskpart 删除损坏分区 → 走「非破坏安装」（Non-destructive install）修复——修复步骤清单放这里
  - 启动菜单左下角模式标识判读：`BIOS`=Legacy、`UEFI`/`IA32`/`AA64`/`MIPS`，用于确认机器实际引导模式

## 学习路径说明

### 前置要求
- 会下载并安装 Windows 软件、能解压 zip/tar.gz
- 熟悉进入 BIOS/UEFI 并修改启动顺序（从 U 盘启动）
- 知道什么是 ISO 镜像，能区分系统盘与 U 盘的盘符/设备名
- Linux 读者：会打开终端、理解 `/dev/sdX` 这类设备名，并有 sudo 权限

### 学完能做什么
- 独立把一块 U 盘制作成 Ventoy 多系统启动盘（Windows 或 Linux 路径）
- 之后只靠「复制文件」随时增删 Windows / Linux / PE / 工具类镜像，无需重复烧录
- 在不丢失镜像的前提下安全升级 Ventoy，并把 U 盘兼作普通存储盘
- 遇到 Secure Boot 注册、启动失败、安装失败、扫描卡顿等常见问题，能按清单自行排查

### 建议学习顺序
- 主路径：第 1 章（原理）→ 第 2 章（准备）→ 第 3 章 Windows 或第 4 章 Linux（按自己平台二选一）→ 第 5 章日常 → 第 6 章排错
- 第 7 章为可选速览，建议在读完第 6 章后按需翻阅，不进入主线
- 动手节奏建议：先完整走一遍第 2+3（或 2+4）做出可用启动盘，再回头补第 1 章的细节；第 5、6 章作为日常参照，随用随查
- 预计用时：边读边做约 1–2 小时可产出一个可用启动盘；排错章节按需查阅
