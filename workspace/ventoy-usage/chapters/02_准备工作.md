## 第二章：开工前的准备——下载、U 盘与备份

原理清楚后，动手前还要备齐三样东西：官方渠道下载的安装包、一块合适的 U 盘、以及被清空前的数据备份。安装是这条主路径上唯一一次会「整盘清空」的操作，把准备做扎实，后面就不会翻车。

### 2.1 下载 Ventoy：认准 GitHub Releases

Ventoy 安装包统一发布在 GitHub Releases 官方页，按平台分两种，命名固定为 `ventoy-<版本>-windows.zip` / `ventoy-<版本>-linux.tar.gz` [^c2-1]。写作时最新稳定版是 **v1.1.17（发布于 2026-07-24）** [^c2-2]；你读到时若有更新，认准标着 Latest 的最新稳定版即可。

| 你的系统 | 下载文件（以 v1.1.17 为例） | 解压后关键文件 |
| --- | --- | --- |
| Windows | `ventoy-1.1.17-windows.zip` | `Ventoy2Disk.exe`（图形界面） |
| Linux | `ventoy-1.1.17-linux.tar.gz` | `Ventoy2Disk.sh`（命令行脚本） |

### 2.2 解压后装包里有什么

Windows 包顶层就是 `Ventoy2Disk.exe`——默认的图形安装器。它本身是 32 位程序，但兼容最常见的 32/64 位 Windows，直接用即可；包内 `altexe` 子目录另有 `Ventoy2Disk_X64.exe` / `Ventoy2Disk_ARM64.exe` 等备用版本，需要时拷到与 `Ventoy2Disk.exe` 同层再运行 [^c2-1]。

Linux 包解压后执行入口是 `Ventoy2Disk.sh`，两条硬规矩：**必须 root 权限**（加 `sudo`），且**必须先 `cd` 进解压目录再执行** [^c2-1]。

### 2.3 U 盘选型

按三条来选：

- **容量 ≥ 镜像总和再留余量**：一个 Windows ISO 常约 5 GB，装三五个就是几十 GB，先估算再买盘。
- **接口 USB 3.0 起步**：大镜像拷贝和启动加载都快得多，USB 2.0 会等到怀疑人生。
- **避开扩容/劣质盘**：标称 64 GB 实际只有 16 GB 的假盘并不少见。买正规品牌，到手先用工具实测容量。

> [!tip] 大白话
> 把扩容盘想成「注水猪肉」：标签写 64 GB，实际能装的只有 16 GB。等你拷到后半段才发现装不下、启动还失败，前面全白干。U 盘是地基，这里别省钱。

### 2.4 先备份，再谈安装

> [!warning] 安装 = 整盘清空
> Ventoy 首次安装会把目标磁盘格式化、清空全部数据，且不可反悔 [^c2-1]。无论 Windows 还是 Linux 路径都一样。动手前，把 U 盘里任何还想留的文件复制到电脑或其他盘，并确认接下来要操作的确实是这块 U 盘、不是系统盘。

### 2.5（可选）校验下载完整性

下载可能拿到「能解压但已损坏」的包。SHA-256 校验能确认文件与官方发布一致 [^c2-3]：在发布页找到对应文件的 SHA-256 值，本地算一次同样的值，一致即通过。

Linux 用 `sha256sum`：

```bash
# 先 cd 到下载目录；文件名按实际下载替换
sha256sum ventoy-1.1.17-linux.tar.gz
# 输出示例：d2b1…0f3e  ventoy-1.1.17-linux.tar.gz  （以发布页公布值为准）
```

Windows 用 `certutil`：

```bat
:: 先切到下载目录
certutil -hashfile ventoy-1.1.17-windows.zip SHA256
:: 输出含一行 64 位十六进制，与发布页公布值比对
```

> [!tip] 大白话
> SHA-256 像文件的「指纹」：内容差一个字节，指纹就完全不同。本地指纹与官方指纹对得上，就说明你下载的包和官方原版一模一样，没下残、没被改。

---

**本章小结**

- 下载认准 GitHub Releases：Windows 选 `ventoy-*-windows.zip`，Linux 选 `ventoy-*-linux.tar.gz`；锚点 v1.1.17（2026-07-24）[^c2-2]。
- Windows 关键文件是 `Ventoy2Disk.exe`（`altexe` 下有备用架构版）；Linux 是 `Ventoy2Disk.sh`，需 root 且要先 `cd` 进解压目录 [^c2-1]。
- U 盘三原则：容量留余量、USB 3.0+、认正品避开扩容盘。
- 首次安装会格式化整盘，动手前务必备份并核对目标盘 [^c2-1]。
- 可选：用 `sha256sum` / `certutil` 校验 SHA-256，与发布页公布值比对 [^c2-3]。

一切就绪，下一步就是把 Ventoy 真正装到这块 U 盘上——先从多数读者走的 Windows 图形界面路径开始。
