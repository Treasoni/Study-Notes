## 共享资料策略

**判定：需要共享资料库**

所有笔记围绕 Claude Code 生态，共享更新目标一致（基于官方最新文档）。统一收集：

1. **Claude Code 官方文档** - 涵盖所有核心功能
2. **官方 CLI 参考** - CLI 命令参考
3. **官方博客/Changelog** - 版本更新日志
4. **MCP 规范文档** - MCP 协议文档

每条资料标注适用笔记范围，避免无关笔记加载不必要资料。

## 覆盖风险

| 风险项 | 说明 | 缓解措施 |
|--------|------|---------|
| 原地更新覆盖原文 | patch-in-place 模式会直接修改原文件 | 每篇先建立 stale_map 和 update_plan，更新前确认 |
| 内容过于陈旧需大改 | 部分笔记可能过时严重，patch 不够需重写 | 如 patch 幅度 >60%，标记需复核并与用户沟通 |
| sortspec.md 非笔记 | 配置文件不应被当作笔记更新 | 默认标记 skip，等用户决定 |
| Dynamic Workflows 较新 | 2026-06-18 内容可能已是最新 | 只做格式统一，内容级更新按需进行 |
