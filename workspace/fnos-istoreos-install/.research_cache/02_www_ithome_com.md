# 飞牛 fnOS 系统虚拟机获 v0.9.0 更新，安装镜像支持选择 img 等格式

[IT之家](https://www.ithome.com/) 5 月 22 日消息，飞牛私有云今日官宣系统虚拟机更新**v0.9.0 版本** ，支持使用 img 安装系统，支持更多格式镜像 (img、img.gz、qcow2)，同时还可以导入导出虚拟机 OVA 镜像等。
IT之家附飞牛 fnOS 系统虚拟机 v0.9.0 更新内容如下：
>   * 支持将虚拟机导出为 OVA 文件
>   * **支持导入 OVA 文件创建虚拟机**
>   * **系统安装镜像支持选择 img 等磁盘镜像文件**
>   * 虚拟磁盘支持导入 qcow2 等磁盘镜像文件
>   * VNC 新增剪贴板功能，支持自动同步本地剪贴板。需要先进入虚拟机编辑并开启 VNC 剪贴板
>   * 虚拟机增加默认的声音设备，支持使用远程桌面时输出声音。之前创建的虚拟机需要编辑保存一次后生效
>   * **显卡类型增加 virtio-gpu 支持** ，选择该虚拟显卡可支持在 Windows 11 系统的虚拟机中调整桌面分辨率
>   * 网卡类型增加 E1000E 支持
>   * **支持编辑硬盘启动位置**
> 

另外，飞牛 fnOS 应用也进行了上新，具体如下：
> ### 驱动上新
>   * **瑞昱 rtw89 无线网卡** ：适用于以下无线网卡，Realtek 8851BE,8852AE,8852BE.8852CE,8922AE
