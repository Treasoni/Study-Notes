## 第 1 章 认识 iStoreOS 与旁路由方案选型

- **篇幅**：短
- **素材引用**：S3, S4, S7, S8, S9
- **涉及的代码/命令/截图点**：无命令；含 1 张拓扑示意图（主路由 → 旁路由 → 设备）与 1 张方案对比表截图位置

### 1.1 iStoreOS 是什么
- 基于 OpenWrt 深度优化的开源智能路由系统，内置 iStore 软件中心，支持 Docker（S7）。
- 全开源、多硬件适配、安全沙箱（S7）。

### 1.2 软路由 / 旁路由：本教程的拓扑
- 旁路由定义：通过 LAN 口接入主路由、分担网络任务、不直接连接互联网、不改变主网络拓扑与 IP（S4）。
- 本教程拓扑：用户已有独立主路由，iStoreOS 虚拟机作为旁路由接入。

### 1.3 旁路由的三种官方方案概览
- 官方方案表格：手动静态 IP / 旁路由 DHCP 接管 / (华硕)浮动网关（S4）。
- 本教程重点：因用户已有独立主路由，只展开前两种，第三种仅提及。
- ⚠️ 铁律预告：一个局域网不能同时存在两个 DHCP（S5）。

### 1.4 两条安装路线选型
- 方法 A：fnOS 虚拟机 UI 直接导入 img 镜像，推荐新手（S8）。
- 方法 B：temp ISO + SSH virsh 挂载 efi 镜像，偏进阶，适用于方法 A 引导失败或想用 UEFI 固件（S9）。

## 第 2 章 前置准备

- **篇幅**：中
- **素材引用**：S1, S3, S6, S8, S9
- **涉及的代码/命令/截图点**：无命令；含固件命名示例与下载页面截图点

### 2.1 准备清单总览
- 一台已装 fnOS 的 x86 设备（有线/聚合网口）、已有独立主路由、浏览器、SSH 客户端（方法 B 用）。

### 2.2 下载 iStoreOS x86_64 固件
- 官方固件仓库目录 fw.koolcenter.com/iStoreOS/x86_64/（S6）。
- 命名规律：`istoreos-{版本}-{日期}-x86-64-squashfs-combined.img.gz`，越前面越新，选日期最新（S6, S8）。
- 方法 A 用 combined 镜像；方法 B 需要 x86_64_efi 目录下的 `-efi.img.gz`（S9）。

### 2.3 安装并准备 fnOS 虚拟机环境
- 应用中心安装「虚拟机」应用；系统设置 → 网络管理 → 启用 OVS（仅有线网口/聚合网口支持，无线不支持）（S1, S8）。
- BIOS/UEFI 开启硬件虚拟化 Intel VT-x / AMD SVM（AMD-V）（S1）。
- Linux 系统（含 OpenWrt/iStoreOS）自带 VirtIO 驱动，无需额外驱动（S1）。

### 2.4 提前知道的两个差异（以官方最新为准）
- 矛盾点 1：img 直导 vs 解压导入 —— S3 官方实机文档说不需解压；S8 论坛教程在导入飞牛 VM 前先解压成 img，且 S8 回帖反馈 gz 直导有时引导失败（S3, S8）。本教程主流程按「先解压成 img 再导入」写。
- 矛盾点 2：默认密码差异 —— S3 说默认 `root/password`；S9 说初始未设密码直接登录后设置（S3, S9）。
- ⚠️ 统一提示：固件文件名、默认密码、路径一律「以官方最新页面为准」。

## 第 3 章 方法 A：用 UI 直导 img 创建虚拟机（主流程）

- **篇幅**：中
- **素材引用**：S1, S2, S8
- **涉及的代码/命令/截图点**：无命令；UI 操作为主，含创建虚拟机各步骤截图点

### 3.1 上传与解压固件
- 把 img.gz 上传到飞牛任意目录，解压出 img 文件（S8）。
- 提示：若直导失败可改试第 5 章方法 B（S8 回帖）。

### 3.2 创建虚拟机（镜像导入与格式转换）
- 创建虚拟机 → 名称 + 操作系统类型 Linux → 选择 img 镜像 → 下一步 → 格式转换（耐心等待）（S8, S1）。

### 3.3 磁盘与网卡配置
- 第一个虚拟磁盘初始 2433 MB，创建时不可改/不可删，创建后可编辑扩容，可加磁盘（最多 8 个）（S8）。
- 添加网卡：多网口小主机可加多个（选 OVS 网口、网络类型、MAC）（S8, S1）。
- 完成创建后先不启动，编辑虚拟机 → 磁盘 → 扩容（iStoreOS 一般 20G 足够）（S8）。

### 3.4 硬件直通（可选，跳过即可）
- 直通前置：BIOS 开 VT-x/AMD-V + IOMMU（VT-d/AMD-Vi），GRUB 声明 IOMMU、禁设备驱动加载、分组隔离（S2）。
- ⚠️ 网卡直通风险：必须确保宿主机保留可用网卡，否则宿主失联；非专业用户不建议（S2）。

## 第 4 章 初始化 iStoreOS 并访问后台

- **篇幅**：短
- **素材引用**：S3, S8, S9
- **涉及的代码/命令/截图点**：`quickstart`；中文化 `uci` 命令；VNC 连接与后台登录截图点

### 4.1 开机与 VNC 连接
- 启动虚拟机，通过 VNC 连接访问；等待自动安装，出现提示时敲回车（S8）。
- 若 VNC 黑屏但能通过 IP 访问，属正常现象，改用浏览器访问（S8 回帖 7.2）。

### 4.2 quickstart 初始化与修改 LAN IP
- 终端输入 `quickstart` 回车（或 `qu` + Tab 补全）（S8）。
- 选 Change LAN IP → 设置局域网未被占用的静态 IP + 子网掩码（S8）。

### 4.3 浏览器访问后台与默认账号
- 浏览器访问刚设置的静态 IP（S8）。
- 默认账号 `root` / 密码 `password`（S8, S3）。
- ⚠️ 矛盾点提示：默认密码跨版本/跨固件有差异（S9），「以官方最新为准」。

### 4.4 中文化设置
- 系统显示英文时，终端执行：
  ```bash
  uci set luci.languages.zh_cn='中文 (Chinese)'
  uci set luci.main.lang='zh_cn'
  uci commit luci
  ```
  （S8 回帖 7.6）

## 第 5 章 备选方案：方法 B（temp ISO + SSH virsh）

- **篇幅**：中
- **素材引用**：S9
- **涉及的代码/命令/截图点**：`gzip -d`、`virsh list --all`、`virsh attach-disk`；UEFI 主板固件选择截图点

### 5.1 适用场景与镜像准备
- 适用：UI 直导引导失败，或想用 UEFI/efi 固件、走 virsh 精确控制（S9）。
- 下载两个镜像：预制引导包 `fnOS_temp.iso` 与正式 efi 镜像（x86_64_efi 目录），上传到飞牛并记录目录路径（S9）。

### 5.2 创建 UEFI 虚拟机
- 飞牛开 SSH（仅管理员）、装虚拟机套件、开 OVS（S9）。
- 新建 VM：操作系统 Linux 6.x-2.6 kernel；主板固件必须选 UEFI；系统镜像选 temp ISO（S9）。

### 5.3 SSH + virsh 挂载正式镜像
- SSH 连接飞牛 → `sudo -i` → 进入镜像目录 → 解压：
  ```bash
  cd /vol1/1001/downloads/
  gzip -d istoreos-24.10.4-…-x86-64-squashfs-combined-efi.img.gz
  ```
- 挂载到 VM：
  ```bash
  virsh list --all
  virsh attach-disk <VM名> /vol1/1001/downloads/…-efi.img vdb --driver qemu --subdriver raw --persistent
  ```
  （S9）

### 5.4 初始化与收尾
- 回到虚拟机 UI 确认新增磁盘，开机 → VNC → `quickstart` → 设 IP → 浏览器访问 → 设置管理员密码 → 网络配置（S9）。
- 完成后回到第 6 章继续配置旁路由。

## 第 6 章 配置旁路由接入现有主路由（核心）

- **篇幅**：长
- **素材引用**：S4, S5, S8, S12（S12 未抓取，仅作补充方向，正文以 S4/S5/S8 为准）
- **涉及的代码/命令/截图点**：后台网络向导 UI 为主；含「配置为旁路由」向导、DHCP 开关、网关/DNS 设置截图点

### 6.1 打开网络向导并配置为旁路由
- 点击网络向导 → 配置为旁路由（S8, S4）。
- 填入静态 IP、子网掩码、网关地址、DNS（默认阿里 DNS 可改）（S8）。

### 6.2 方案一：手动静态 IP（最简，适合新手）
- 主路由：保持默认，DHCP 开启（S4）。
- iStoreOS：关闭 DHCPv4 服务，只做网关转发（S4, S8）。
- 适合只想让部分设备走旁路由的场景。

### 6.3 方案二：旁路由接管 DHCP（适应性最广）
- 主路由：关闭 DHCP，网关设旁路由（S4）。
- iStoreOS：开启 DHCP 全面接管（S4）。
- ⚠️ 铁律：一个局域网不能同时存在两个 DHCP（S5）。

### 6.4 如何让指定设备走旁路由
- 需要走旁路由的设备改成手动 IP，网关和 DNS 都指向旁路由的 IP（S8 回帖 / S12）。
- 不需要多网口机器，单网口也可做旁路由（S8 回帖）。

### 6.5 开启 IPv6（可选）与常见问题速查
- 开启自动获取 IPv6（可选，后续可做 DDNS 远程访问）（S8）。
- 排错速查：网络 → 接口 → LAN 勾选「使用默认网关」；网络 → 防火墙 → 区域 LAN 勾选「IP 动态伪装」（小米等主路由常见）（S5）。

## 第 8 章 常见问题排查

- **篇幅**：中
- **素材引用**：S2, S3, S5, S8
- **涉及的代码/命令/截图点**：以 10 行「现象 → 原因/解决」速查表为主；中文化 uci 命令复用第 4 章

### 8.1 安装与启动类问题
- img.gz 直导引导失败 → 先解压成 img 再导入，或改试方法 B（7.1, S8）。
- VNC 黑屏无显示但 IP 可访问 → 正常，改用浏览器访问（7.2, S8）。
- 启用 OVS 后重启宿主失联 → OVS 网络中断，保留可用管理网卡（7.3, S8）。
- 默认 192.168.100.1 访问不了后台 → 确认 LAN 口与网段，用 quickstart 改同网段静态 IP（7.4, S3/S8）。
- 改 LAN IP 后重启又恢复默认 → 配置未保存/未生效，重新走网络向导保存（7.5, S8）。

### 8.2 网络与访问类问题
- 系统英文无中文 → 终端执行 uci 中文化命令（7.6, S8）。
- 固件默认无科学上网插件 → 自行安装（7.7, S8）。
- 磁盘根目录只有 2G → 手动格式化其余空间（7.8, S8）。
- 网卡直通导致宿主失联 → 直通前保留宿主可用网卡，需要 IOMMU/VT-d，非专业用户不建议（7.9, S2）。
- 设置后设备无法上网 → 网关/DNS 指向；LAN 默认网关打勾；防火墙 IP 动态伪装（7.10, S5/S8）。

### 8.3 排错通用原则
- 所有默认密码、固件文件名、路径以官方最新页面为准；飞牛底层虚拟化基于 KVM/libvirt 属社区推断（S9），官方无单点说明。

## 前置准备清单

开始阅读前，请确认以下文件/工具/条件已就绪：

- [ ] 一台已安装飞牛 fnOS 的 x86 设备，且 BIOS/UEFI 已开启硬件虚拟化（Intel VT-x / AMD SVM）（S1）
- [ ] 宿主机使用有线网口或聚合网口（无线网口不支持 OVS）（S1）
- [ ] 已有独立主路由（本教程以其为上游，按所选方案调整其 DHCP/网关）
- [ ] 在 fnOS 应用中心安装「虚拟机」应用，并在系统设置 → 网络管理启用 OVS（S1, S8）
- [ ] 下载 iStoreOS x86_64 固件：方法 A 用 `squashfs-combined.img.gz`（S6, S8）；方法 B 需 `x86_64_efi` 目录下的 `-efi.img.gz` 与 `fnOS_temp.iso`（S9）
- [ ] 压缩/解压工具（把 img.gz 解压为 img）（S8）
- [ ] 浏览器（访问 iStoreOS 后台；VNC 作为备选）（S8）
- [ ] SSH 客户端（方法 B 需要；并在飞牛系统设置开启 SSH）（S9）
- [ ] 建议先通读官方文档：飞牛虚拟机帮助（S1）、iStoreOS x86 安装文档（S3）、iStoreOS 旁路由实践（S4）
