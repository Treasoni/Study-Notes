- **小节清单**：

  - ### 1.2 三大寻址：IP 地址 / MAC 地址 / 端口号 的分工与配合
  - ### 1.3 封装与解封装：数据逐层加头、逐层剥头的过程
  - ### 1.4 TCP 与 UDP 的定位差异（面向连接可靠 vs 无连接轻量）
- **素材引用**：板块一（1.1）
- **篇幅**：中（约占全篇 10%）

  - ### 3.4 半关闭（Half-Close）vs 半开连接（Half-Open）的区分

## 第四章：可靠传输——确认、窗口与拥塞控制

- **本章目标**：理解 TCP 如何通过字节序号、累计确认、滑动窗口、拥塞控制与超时重传，实现既可靠又高效的字节流传输。
- **小节清单**：
  - ### 4.1 可靠传输基础：字节序号、累计确认、ARQ、延迟 ACK 与重复 ACK 策略
  - ### 4.2 流量控制：滑动窗口（RWND）、窗口三种操作、零窗口死锁与持久计时器
  - ### 4.3 拥塞控制：慢启动、拥塞避免、快速重传、快速恢复（cwnd / ssthresh / FlightSize）
  - ### 4.4 超时与重传：RTO 计算（RFC 6298）、Karn 算法、指数退避；发送窗口 = min(cwnd, rwnd)
- **素材引用**：板块三（3.1、3.2、3.3、3.4、3.5）
- **篇幅**：长（约占全篇 22%）
- **代码/命令**：可选——`sysctl` 查看重传/窗口内核参数；如需在章内加入最小 Python Socket 演示（echo server/client）加深印象，需另行补充素材（当前深度素材中仅有实验建议、无现成代码）

## 学习路径说明

### 前置要求
- 有基本网络常识（IP 地址、端口、什么是协议）——用户「有了解」基础已满足，无需系统预学。
- 会使用命令行终端；抓包实验需要 `sudo`/管理员权限（tcpdump、Wireshark）。
- 一台可联网电脑；macOS/Linux 可直接跑 tcpdump 与 ss，Windows 可改用 Wireshark + PowerShell 的 `netstat`。

### 学完能做什么
- 看懂一次抓包中的三次握手、四次挥手与状态迁移，能解释每个包上的 seq/ack 含义。
- 用 tcpdump / Wireshark / ss 快速定位端口占用、连接状态分布与监听队列积压。
- 独立排查 CLOSE_WAIT、TIME_WAIT、SYN 洪水、半开连接四大高频问题，并能区分「调内核参数」与「治本（代码/架构）」。
- 理解 TCP 可靠传输与拥塞控制的核心机制，为继续学习 HTTP/2、TLS、QUIC 打下基础。

### 建议学习顺序
- 第 1~4 章按顺序精读，建立概念主线（约 2~3 天）。
- 第 5 章动手实操抓包，然后**回到第 3 章**用 tcpdump 验证握手/挥手（约 1 天）。
- 第 6 章在测试环境演练排查（可用 `nc`/`curl` 自行制造 CLOSE_WAIT、TIME_WAIT 观察）（约 1 天）。
- 第 7 章速查表随用随查，进阶路线按需延伸（半天）。
