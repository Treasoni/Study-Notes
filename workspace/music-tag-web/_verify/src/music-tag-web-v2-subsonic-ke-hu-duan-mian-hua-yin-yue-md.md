# 棉花音乐

## 随时随地听音乐

支持Subsonic媒体服务器（Music Tag Web），本地歌曲、百度网盘、阿里云盘、WebDAV、GoogleDrive、OneDrive、Dropbox等网盘歌曲播放，支持Plex、Emby、Jelly、，支持Android、iOS, Windows、Mac、Linux平台

### 棉花音乐的功能

#### 歌曲源

支持本地歌曲、百度网盘、阿里云盘、WebDAV、GoogleDrive、OneDrive、Dropbox等网盘歌曲播放

#### 媒体服务

支持Plex、Emby、Jelly、Subsonic媒体服务器

#### 多平台支持

支持Android、iOS、Windows、Mac、Linux平台

#### 播放历史

记录播放历史

#### 支持歌单

支持创建歌曲

#### 播放器主题

支持多样的播放器主题
