# 项目介绍

『音乐标签V2』Music Tag Web V2 是集合音乐标签刮削和音乐播放一体的个人音乐库解决方案。

*<mark style="color:purple;">工欲善其事必先利其器，先确定对音乐库的需求，才能选择合适的媒体程序。</mark>*

官网地址：<http://www.musictagweb.com/>

**V2 版本具有** [**V1 版本**](https://xiers-organization.gitbook.io/music-tag-web)**的所有功能**

\
**V2 还有的功能：**

<figure><img src="https://1560078921-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FuE4PkIICNz2eL9KnNA7s%2Fuploads%2FuR4qYQxcoP1muFSeA41X%2Fimage.png?alt=media&amp;token=f3ea1e5c-e4af-4756-9a21-79bfd75381e2" alt=""><figcaption><p>Music Tag Web V2 首页预览</p></figcaption></figure>

* **首页总览：**&#x76F4;观展示音乐库概览和播放记录
* **异步任务中心：**&#x6279;量刮削、批量编辑、修复清理等耗时操作统一在后台执行，并支持任务进度跟踪与日志查看。
* **音乐收藏与播放：**&#x652F;持将歌曲、专辑、艺术家沉淀为个人音乐收藏，并兼容 Subsonic / Open Subsonic 生态，实现网页端播放与第三方客户端接入。
* **跨设备播放同步**：支持播放队列、当前播放曲目与播放进度的跨端同步，用户可在不同浏览器或客户端之间无缝续播。
* **多端同播**：支持创建共享听歌房间，实现多人加入、在线状态同步与播放控制协同，适合家庭共享和远程一起听歌。
* **后台自动刮削入库：**&#x6301;对新增目录进行后台扫描、识别与元数据整理，降低手动入库成本，提升音乐库维护效率。
* **元数据批量编辑**：支持大规模音乐文件的标签编辑、批量修复与整理操作，适合重度曲库用户快速规范资料。
* **元数据版本管理**：自动记录每次元数据修改历史，支持版本查看、差异对比与一键回退，让整理工作更可控、更安全
* **智能家居集成：**&#x4E0E;小爱智能音箱无缝对接，通过语音唤醒词播放本地音乐。
* **云音乐管理：**&#x652F;持AList云端音乐文件的管理和抓取，方便添加至收藏库及播放。
* **刮削报告：**&#x751F;成更详细的刮削报告，刮削进度信息。
* **外置歌词：**&#x652F;持外挂歌词api。
* **智能歌单创建：**&#x652F;持基于规则自动生成动态歌单，持续按条件更新内容，打造个性化自动歌单体系。
* **音乐库去重与洗版**：支持重复文件检测、相似内容分析与更优版本替换，帮助用户完成去重、洗版和曲库质量治理。
* **插件模块**：内置多种标签源插件，并支持用户上传自定义插件，持续扩展刮削来源、歌词能力与批处理流程。
* **角色与权限管理**：支持不同用户角色与访问权限划分，兼顾“音乐收藏管理者”与“普通听众”的使用需求。
