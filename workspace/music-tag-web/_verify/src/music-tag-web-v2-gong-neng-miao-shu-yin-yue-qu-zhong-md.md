# 音乐去重

查找出重复的文件 不会自动删除您的文件，可以到操作记录中查看重复文件进一步删除操作。

<figure><img src="https://1560078921-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FuE4PkIICNz2eL9KnNA7s%2Fuploads%2FYVrmhjaRvJyipUE7p83s%2Fimage.png?alt=media&amp;token=994e75af-5760-4286-a758-402b1635eaed" alt=""><figcaption><p>文件去重</p></figcaption></figure>

1. 功能位置在：操作台-勾选目录-重复文件检查
2. 执行成功后操作记录中可以查看到记录\
   ![](https://1560078921-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FuE4PkIICNz2eL9KnNA7s%2Fuploads%2FAwS4HNPdj9hF5nMjfTmL%2Fimage.png?alt=media\&token=eb703165-14db-4201-a833-cf986ea4704b)
3. 操作记录详情中罗列出检查到的重复文件，您可自行选择需要删除的重复文件\
   ![](https://1560078921-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FuE4PkIICNz2eL9KnNA7s%2Fuploads%2FnlwatscptZQfypxexNa9%2Fimage.png?alt=media\&token=18720747-5911-43bb-a3a1-2a695fb07343)
