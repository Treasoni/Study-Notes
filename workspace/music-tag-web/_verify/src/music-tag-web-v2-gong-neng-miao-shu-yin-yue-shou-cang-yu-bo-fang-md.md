# 音乐收藏与播放

Open Subsonic 协议的播放服务器。登录的 host 是站点 ip:8002, 账号密码在后台管理里subsonic 用户中查看并修改。

<figure><img src="https://1560078921-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FuE4PkIICNz2eL9KnNA7s%2Fuploads%2F9BnywCQx0sYV5VOjTUDD%2Fimage.png?alt=media&amp;token=8bc2d733-bc03-46c6-b3d4-4fc5f24e4dcd" alt=""><figcaption><p>音乐收藏-专辑</p></figcaption></figure>

1. **导入收藏**，在操作台中，勾选想要导入的目录，导入收藏，等待导入后可在音乐收藏中展示。
2. **实时编辑元数据**，在专辑中-歌曲-编辑按钮，可跳转至操作台修改元数据，修改后立即生效。\
   ![](https://1560078921-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FuE4PkIICNz2eL9KnNA7s%2Fuploads%2FKxfFMN0shB5AD0M14Z7V%2Fimage.png?alt=media\&token=faae7a36-e6f8-4d65-b985-374c7958c958)
3. **刮削艺术家/自定义艺术家封面**，支持手动，自动刮削艺术家封面，选择自己喜欢的封面。\
   ![](https://1560078921-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FuE4PkIICNz2eL9KnNA7s%2Fuploads%2FOtMdcmkEj6WbcBd1k5lR%2Fimage.png?alt=media\&token=ff84ad81-658d-4be8-a418-40ed5a262e86)
4. **支持所有 subsonic 的客户端**。 基于 Open Subsonic 协议音乐播放接口。
5. **subsonic 修改密码。**&#x61;dmin/后台中 subsonic 用户中，修改 api token 即是密码。\
   ![](https://1560078921-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FuE4PkIICNz2eL9KnNA7s%2Fuploads%2FgU15ILC39Qxw3WCL6F2l%2Fimage.png?alt=media\&token=4af5aced-e0d1-4851-abc6-77b49b566e85)\
   修改完密码后，需要重新登录后刷新页面。
6. **同步删除不存在的音乐，**&#x5DF2;经导入收藏的音乐，后续在文件管理中删除了，收藏中还存在可在其他设置-删除不存在收藏中同步删除，或着直接通过 操作台中的删除文件夹功能删除文件。该功能会同时删除音乐收藏中的音乐。
7. **封面不显示问题，**&#x4E13;辑/艺术家封面不显示，[具体见常见问题中解答。](/music-tag-web-v2/chang-jian-wen-ti.md)
