# 箭头音乐

箭头音乐，一款专注于本地音乐播放与深度管理的工具，以「专业调校」为核心，为每一位音乐爱好者量身定制沉浸式聆听方案。

## 特色

* **精准音高调节**：自由升降调，适配不同演唱、演奏需求。无论是翻唱练歌时匹配声线，还是乐器演奏时校准调性，都能一键搞定，音质无损还原。
* **专业均衡器调校**：多频段音效自定义，低音沉稳、中音饱满、高音清亮，随心打造专属听感。不管是摇滚的炸裂、古典的细腻，还是流行的通透，都能精准拿捏。
