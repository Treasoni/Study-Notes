# Music Tag Web

## Music Tag Web

- [项目介绍](https://xiers-organization.gitbook.io/music-tag-web/xiang-mu-jie-shao.md): 『音乐标签』Web版是一款可以编辑歌曲的标题，专辑，艺术家，歌词，封面等信息的应用程序， 支持FLAC, APE, WAV, AIFF, WV, TTA, MP3, MP4, M4A, OGG, MPC, OPUS, WMA, DSF, DFF等音频格式。
- [快速开始](https://xiers-organization.gitbook.io/music-tag-web/kuai-su-kai-shi.md): 快速开始部署您的应用
- [手动修改标签](https://xiers-organization.gitbook.io/music-tag-web/shou-dong-xiu-gai-biao-qian.md): 手动刮削，针对个别的音乐文件进行修改
- [批量修改](https://xiers-organization.gitbook.io/music-tag-web/pi-liang-xiu-gai.md): 勾选多个文件或文件夹进行批量修改文件中相同的元数据（注意是手动填写）
- [自动批量修改](https://xiers-organization.gitbook.io/music-tag-web/zi-dong-pi-liang-xiu-gai.md): 自动从你选定的标签源中匹配并保存到音乐文件中
- [整理文件夹](https://xiers-organization.gitbook.io/music-tag-web/zheng-li-wen-jian-jia.md): 将音乐文件，以元数据中的值进行分组到文件夹中
- [简繁体转换](https://xiers-organization.gitbook.io/music-tag-web/jian-fan-ti-zhuan-huan.md)
- [拆分文件名称](https://xiers-organization.gitbook.io/music-tag-web/chai-fen-wen-jian-ming-cheng.md): 你收集的音乐文件中，只有文件名称存在歌曲基本信息，元数据中没有的情况，可以快速的将文件名称中的基本信息嵌入到音乐元数据中。
- [切割音轨](https://xiers-organization.gitbook.io/music-tag-web/qie-ge-yin-gui.md): 使用CUE专辑标记文件无损切割整轨CD音轨
- [V2 版本](https://xiers-organization.gitbook.io/music-tag-web/v2-ban-ben.md): 是集合音乐标签刮削和音乐播放一体的个人音乐库解决方案。
