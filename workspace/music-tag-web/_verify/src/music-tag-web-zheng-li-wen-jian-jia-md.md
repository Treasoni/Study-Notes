# 整理文件夹

将音乐文件，以元数据中的值进行分组到文件夹中

<figure><img src="https://3761008155-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2Fg0Qb0o78UzRYrKFIbuBp%2Fuploads%2FAcFAm6hUq2ljFu6xHcIY%2Fimage.png?alt=media&amp;token=6af7a27b-fdb1-4c3f-9d16-7a89df60995a" alt=""><figcaption><p>整理文件夹</p></figcaption></figure>

支持多级目录（可选）\
整理后的根目录：意味着整理后文件会存放在这个目录下。

选择多级目录，会更加音乐的元数据进行整理分组文件。

## 删除空文件夹

删除文件夹下\*无任何文件\*的文件夹。\
例如 A/B/C 都为空， 会优先将 C 目录删除，不会将 A/B/C 级联删除，（如果想级联删除，再执行两次）
