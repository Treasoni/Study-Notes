## 第八章：分人群选型——一张决策流程 + 场景清单

前面七章把三条路线拆开看过了，这一章把它们收拢成"我到底该选哪条"。先给结论：**选哪条不取决于哪条"更好"，而取决于你对画质的要求有多高、以及手头有没有现成的 NAS。** 下面先给一张决策流程，再给一张"你是哪类人 → 走哪条路"的清单，最后补一句三条网盘路线都躲不开的前提。

### 8.1 一张决策流程图：先问自己三句话

从最省事的一头开始问，命中就停：

1. **"我只想方便地看，画质差不多就行"** → **网盘自带播放 + 会员**。
   非会员普遍被限速（实测同一份 1.03GB 文件、同一约 100Mbps 网络：百度 96–170KB/s、夸克 650–700KB/s、115 140–150KB/s，开会员后普遍提到 7–11MB/s，据 S6 实测），所以"够用"这条路通常要搭一个会员。够用就好是正当选择，不必为了"更高级"硬上自建。
2. **"我要统一播放器 / 媒体库（Emby、Jellyfin、Kodi 之类）管理，又不想占本地硬盘"** → **302 直链播放**（OpenList/Alist 挂载后交客户端播放）。
   两个限制要提前知道：一是**它可能仍是转码后的版本**——"夸克能 302 的直链一定是转码的"（S15），1080P 与动漫类压缩较明显；二是**转码直链有功能损失**：多音轨只能放默认音轨、视频内封字幕会丢失（S2）。另外 302 的本质是让客户端直接"异地"从网盘取数据，请求与流量并不经过你的 NAS（S15，302 代理说明）。
3. **"我追原盘 / HDR / 杜比，或者要小众资源、隐私、离线"** → **下载到本地（或 NAS）**。
   4K 蓝光 Remux 码率可超 80Mbps、单片 60–80GB（S11）；对画质有要求、觉得低码率"根本就看不成"的人，自建本地库最解忧（S9 社区观点）。

> [!tip] 大白话
> 把三条路线想成三种买菜方式：网盘自带播放＝**在别人家客厅蹭电视**（最省事，但人家放什么清晰度你管不了）；302 直链＝**借把钥匙自己开门取货**（取得快、能自己下厨，但货在别人仓库，可能已被"降级"）；本地下载＝**把货搬回自家仓库**（想怎么做怎么做，代价是仓库和搬运费）。所以先看你多在意"这口菜的火候"，再问你有没有仓库。

> [!warning] 证据缺口
> 该点为缺口/推断：**Plex 官方 Direct Play（直连）与转码的对照文档本次未取到（403）**。因此"客户端直连 vs 服务端转码"在 Plex 侧的权威依据缺失，本处只按 S2、S15 描述 302 直链的转码现象，不引用 Plex 官方结论作依据。

### 8.2 场景清单表：你是哪一类人

| 你大概是这样的人 | 推荐路线 | 关键理由 / 要接受的代价 |
| --- | --- | --- |
| 只刷刷综艺剧集，对画质不敏感，想省心 | 网盘自带播放 + 会员 | 开会员即解锁速度，不折腾（S6、S9） |
| 想用统一播放器 / 媒体库管理，本地空间紧张 | 302 直链播放 | 起播通常 10 秒内，但可能转码、字幕/音轨受限（S15、S2） |
| 追 4K 原盘 / HDR / 杜比，对画质挑剔 | 本地下载（或 NAS） | 画质上限；代价是 40TB 盘才得 20TB、多屏需 2.5GbE/10GbE（S11） |
| 常找小众 / 冷门资源 | 本地下载（或 NAS） | 网盘"临时找不到"时本地随时可取（S9） |
| 内容偏私密，在意隐私 | 本地下载（或 NAS） | 社区经验：私密内容更适合放本地（S9，个人观点） |
| 经常断网 / 出差，需要离线看 | 本地下载（或 NAS） | 离线可用是本地不可替代点（S9） |
| 已经有 NAS，顺手搭个影视库 | 本地下载（NAS） | NAS 可复用、摊薄成本（S9） |

最后这条前提要贯穿全文：**无论走哪条网盘路线，都要接受平台条款风险**。会员协议里保留了大量单方权力——可单方变更、调整、取消会员权益，可在违约时删除内容、限制上传下载播放分享、中止或终止服务，服务终止后"已收取的费用不予退还"；账号最多 6 台设备、同一时间最多 2 台，账号间数据也无法转移（S13 会员协议）。选网盘方案，这些是打包一并接受的。

### 小结

- 选型不是选"最好"，而是看**画质要求**与**是否已有 NAS**两件事。
- 够用党 → 网盘自带播放 + 会员；媒体库党 → 302 直链（注意转码与字幕/音轨限制）；原盘党 → 本地 / NAS。
- 302 直链可能仍是转码版本（S15）；转码直链多音轨仅默认音轨、内封字幕丢失（S2）。
- 网盘路线共同代价是平台条款风险（S13）；本地路线共同代价是硬盘、网络与维护（S11）。
- 缺口：Plex 官方"直连 vs 转码"对照文档未取到，相关权威依据暂缺。
