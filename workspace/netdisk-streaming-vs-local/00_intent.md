## 用户原始问题

1. 我把影视放到网盘中，我直接用网盘看不行吗？那我用 302 重定向的直链播放网盘的影视有什么区别？而且网盘中看影视还可以用网盘的优化功能。
2. 我如果把影视放到网盘中也能看，那我为什么还要下载放到本地硬盘中？

## 研究计划

### 核心对比对象（三选一/多选组合）
| 编号 | 方式 | 说明 |
| --- | --- | --- |
| A | 网盘自带播放 | 网盘 App / 网页端直接在线播放，含网盘的转码、清晰度增强等「优化功能」 |
| B | 302 直链播放 | 通过 OpenList/Alist 等把网盘挂载，再经 302 直链交给第三方播放器 / Emby / Jellyfin / Kodi 播放 |
| C | 下载到本地 | 影视文件落到本地硬盘（或 NAS），本地播放 |

### 探索方向
1. 三种播放方式的机制差异（谁在解码、谁在传输、播放器能力差异）
2. 网盘「优化功能」（在线转码、多分辨率、HDR/清晰度增强、画质）到底是什么、有什么代价
3. 为什么还要下载到本地：离线可用、画质/原盘、稳定流畅、隐私与版权风险、长期保存、成本

### 重点收集
- **核心概念**: 直链 / 302 / 挂载 / 网盘转码 / 原画与压缩 / 限速 / 会员带宽 / 离线缓存 / 本地 NAS 存储
- **对比维度**: 画质、流畅度（卡顿/缓冲）、成本（会员/电费/硬盘）、离线能力、隐私与封号风险、长期可保存性、多设备与多用户、维护成本
- **常见坑**: 网盘限速/封号、302 直链过期、转码画质损失、网盘内容被删、本地硬盘容量与备份
- **工具链**: 网盘 App、OpenList/Alist、Emby/Jellyfin/Plex/Kodi、NAS（fnOS/群晖等）、下载工具
- **信源偏好**: 官方文档（网盘/媒体中心）、社区讨论与实测经验、技术博客
