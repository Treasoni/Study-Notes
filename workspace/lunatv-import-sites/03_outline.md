### 第一章：先搞懂 lunatv 的「源」机制
- **篇幅**：中（约 1,800 字）
- **覆盖要点**：空壳聚合播放器定位、api_site JSON 源格式、苹果CMS V10 接口标准、远程订阅与多源聚合权重
- **素材引用**：#A2, #B1, #B2, #B3
- **代码示例**：有（api_site JSON 完整示例、苹果CMS V10 接口地址示例）

#### 1.1 LunaTV 是什么：空壳聚合播放器
- 不存储视频、只聚合源；功能矩阵速览（网盘搜索、ACG 种子、IPTV、Emby、YouTube、Bilibili、短剧）
- 素材：#B1, #A2

#### 1.2 核心源格式：api_site JSON
- 源对象字段：key（小写字母/数字、保留名 openlist/xiaoya/emby*）、api（必填）、name（必填）、detail（可选）
- 顶层字段：cache_time（缓存秒数，建议 3600-7200）、custom_category（豆瓣搜索词数组）
- 素材：#A2, #B3

#### 1.3 影视站接入标准：苹果CMS V10 接口
- 接口基础地址（`/api.php/provide/vod/`）、from 路径段、返回 JSON 关键字段（vod_play_from、type_name）、浏览器验证法
- 素材：#B2, #A2

#### 1.4 远程订阅与多源聚合
- Base58 解码链路（bs58.decode → UTF-8 → 存 ConfigFile）、SourceConfig 扩展字段（weight/disabled/proxyMode/from）、refineConfig 合并
- 素材：#B3, #A2

### 第三章：把影视站导入 lunatv（核心实操）
- **篇幅**：长（约 3,500 字）
- **覆盖要点**：登录管理后台、订阅 URL 导入、手动 api_site JSON 加源、保存与验证、回首页播放
- **素材引用**：#C2, #A2, #A4, #B3
- **代码示例**：有（订阅 URL、api_site JSON 手动加源段、docker-compose 环境变量段）

#### 3.1 准备：登录管理后台
- 入口 `/admin`；默认账号取决于部署方式（懒猫版 admin/admin123 vs Compose 自设 USERNAME/PASSWORD）
- 素材：#C2, #A2

#### 3.2 方法一：订阅 URL 导入（推荐）
##### 3.2.1 操作步骤
- 管理面板 → 配置文件 → 订阅URL 粘贴 → 打开「自动更新」→ 点「拉取配置」
##### 3.2.2 关键：点「保存」
- 忘记保存是配置不生效的第一大坑；拉取成功显示配置代码即成功
- 素材：#C2, #B3

#### 3.3 方法二：手动添加单个站

- 素材：#A2, #A4

#### 3.4 验证与播放

## 学习路径说明

### 前置要求
- 已在本机部署并启动 lunatv（能打开 Web UI）；本笔记不覆盖从零部署
- 能操作浏览器访问管理后台（/admin）
- 基本了解 JSON 结构（手动加源时会用到）
- 可选：会看 docker-compose / 环境变量（第四章排错用到）

### 学完能做什么
- 判断任意一个影视网站能否接入 lunatv（苹果CMS V10 接口验证）
- 用订阅 URL 一键导入现成影视源，也能手动添加单个站
- 定位并解决导入后的常见问题（配置不生效、源失效、刮削失败、部署环境问题）
- 用 CORSAPI 中转被墙影视站，扩展网盘 / Emby / IPTV 等更多内容源

### 建议学习顺序
- 第一章快速通读（约 20 分钟）：建立源机制概念，为实操打底
- 第二章 + 第三章为核心实操（约 40–60 分钟）：照着走一遍「找到站 → 导入 → 能播放」
- 第四章排错建议边做边查：遇到问题再回来对号入座
- 第五章进阶可选：跑通基础后按需学习
