## 学习路径说明

### 前置要求
- 已安装 Linux 系统（或 WSL/虚拟机），能打开终端
- 了解基本的计算机文件系统概念
- 会用 `ls`、`cd` 等最基础的命令

### 学完能做什么
- 熟练操作文件和目录，高效查找所需内容
- 使用 grep/sed/awk 三剑客处理日志和文本数据
- 监控系统状态、管理服务和排查进程问题
- 使用网络工具诊断常见的连通性故障
- 正确设置文件权限，保障系统安全
- 管理磁盘空间和软件包
- 通过管道组合命令，编写高效的一行命令

### 建议学习顺序
1. **第一章 → 第二章**（打好文件操作基础）
2. **第三章**（文本处理核心技能，需要多练习）
3. **第四章**（系统管理入门）
4. **第五～六章**（网络和权限，可并行学习）
5. **第七章 → 第八章**（磁盘和包管理，按需参考）
6. **第九章**（综合提升，贯穿全书）

> 每章都配有命令速查表，后续可作日常参考手册使用。
