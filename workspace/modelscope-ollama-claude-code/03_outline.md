## 学习路径说明

### 前置要求
- 能在终端复制粘贴命令（Windows 用 PowerShell，macOS/Linux 用 Bash）
- 建议 8GB 以上内存；有 NVIDIA 显卡（驱动 551.61+）可获 GPU 加速，纯 CPU 也能跑通但较慢
- 可访问国内网络（ModelScope 为国内源，通常无需代理；Ollama 官网安装包下载视网络环境而定）

### 学完能做什么
- 从 ModelScope 下载任意 GGUF 量化模型到本地
- 用 Ollama 导入 GGUF 并创建、运行、管理本地模型
- 让 Claude Code 免 Anthropic API Key 直连本地 Ollama 模型，数据不出本机
- 遇到下载失败、显存不足、连不上服务等常见问题时能自查自修

### 建议学习顺序
- 按第 1 → 2 → 3 → 4 → 5 章顺序跟做，约 1.5-2.5 小时；第 6 章作为「遇到问题时查阅」的速查表，可随时翻阅
- 第 2、3、4 章均可在对应环节独立验证；第 5 章是串讲，建议在所有组件就绪后完整跑一遍
