### 第 1 章：显存是什么？GPU 的专属工作台

- **学习目标**：让零基础读者一眼分清显存与内存，看懂容量/带宽/位宽/频率四个参数，记住「容量决定装不装得下、带宽决定快不快」。
- **小节结构**：
  - 1.1 CPU 与 GPU 的分工
    - 1.1.1 为什么 GPU 需要一块「专属」存储
    - 1.1.2 显存：焊在显卡上、与 GPU 直连的高速存储
  - 1.2 显存 vs 内存：一场「不可互换」的误会
    - 1.2.1 服务对象 / 容量 / 带宽 / 位置 / 成本对照表
    - 1.2.2 为什么「加内存条」救不了显存不足
  - 1.3 显存四大参数：容量、频率、位宽、带宽
    - 1.3.1 带宽 = 频率 × 位宽 ÷ 8
    - 1.3.2 落地例子：RTX 4090 ≈ 1TB/s、RX 7900XTX ≈ 960GB/s
  - 1.4 容量 ≠ 性能：够用即可
    - 1.4.1 分辨率参考：1080P ≈ 6GB / 2K ≈ 8GB / 4K ≥ 12GB
    - 1.4.2 爆显存（崩溃报错）vs 爆内存（整机卡顿）
  - 1.5 显存家族扫盲：GDDR vs HBM
- **篇幅**：中
- **覆盖要点**：显存/内存/GPU 分工、四大参数与带宽公式、容量≠性能、GDDR vs HBM、AI 入门 12GB 起步
- **素材引用**：D1#1、D1#2、D1#3、D1#4
- **代码示例**：无
- **大白话类比**：厨房分工（CPU 总厨用备料台 / GPU 炒锅队用猛火灶台）、水站四件套（水池 / 流速 / 水管直径 / 进水总速度）、高速公路（位宽=车道数、速率=时速）

### 第 2 章：大模型为什么吃显存

- **学习目标**：能说出「权重固定月租 + KV Cache 按量计费」两张显存账单，会用「参数量 × 精度」估算权重显存（7B FP16 ≈ 14GB），并理解上下文长度和并发是显存杀手。
- **小节结构**：
  - 2.1 模型为什么必须装进显存才能跑
  - 2.2 权重：模型的「固定身价」
    - 2.2.1 参数量：7B = 70 亿个参数
    - 2.2.2 精度：FP32/FP16/INT8/INT4 每参数占几个字节
    - 2.2.3 估算公式：权重显存 = 参数量 × 每参数字节数
    - 2.2.4 动手算：7B FP16 ≈ 14GB、32B ≈ 60GB
  - 2.3 KV Cache：每次对话的「临时便签」
    - 2.3.1 为什么需要它（以存代算，避免重复计算）
    - 2.3.2 随上下文长度 × 并发线性增长
    - 2.3.3 长上下文为什么是显存杀手
  - 2.4 推理还有哪些开销：激活值 + 框架开销 + 安全系数
  - 2.5 顺带一提：训练 vs 推理（为什么训练更吃显存）
- **篇幅**：中
- **覆盖要点**：参数量、精度、权重显存公式、KV Cache、上下文长度、并发、激活值/框架开销/安全系数、训练系数
- **素材引用**：D2#1、D2#2、D2#3、D2#4（作进阶脚注）
- **代码示例**：无
- **大白话类比**：大词典+墨水（精度决定每个词条用几格墨水）、固定月租+按量计费（权重 + KV Cache）、书签/临时便签（KV Cache）、停车场（并发 × KV Cache）、草稿本+账本（训练）

### 第 3 章：量化——把大模型塞进显存的钥匙

- **学习目标**：理解量化是用少量精度换显存减半以上，认识 Q4_K_M 主流档位，记住「量化后权重 ≠ 实际总需求」。
- **小节结构**：
  - 3.1 为什么需要量化（装不下的问题）
  - 3.2 量化是什么：精度与压缩比
    - 3.2.1 FP16 → INT8 → INT4（2B → 1B → 0.5B）
    - 3.2.2 精度损失：Q4 能力下降约 1-3%，严肃使用建议 Q5_K_M
  - 3.3 常见量化档位（Q4_K_M / Q8）与压缩率直觉
  - 3.4 关键提醒：量化后权重还要 + KV Cache + 开销 + 安全系数
- **篇幅**：短
- **覆盖要点**：量化原理、压缩比、Q4_K_M 首选档位、精度损失、量化≠全包
- **素材引用**：D2#1、D3#1、D3#3、D3#4（NF4/双量化）
- **代码示例**：无
- **大白话类比**：行李打包（Q4 高压 zip、Q8 轻压缩、双量化=抽真空）

## 学习路径说明

### 前置要求

- 无需编程经验，会用命令行/终端输入命令即可
- 建议有一台带 NVIDIA GPU 的电脑（没有也能读懂前 3 章，但第 4 章实战需要动手环境）
- 不需要先学深度学习理论

### 学完能做什么

- 分得清显存、内存、硬盘，看懂显卡参数（容量/带宽/位宽）
- 用公式 + 速查表估算「我的显卡能跑多大模型」
- 用 Ollama 一行命令在本地跑起量化模型，并确认它在用 GPU
- 遇到 CUDA out of memory 能按三板斧自行排障
- 知道 vLLM、多卡、MoE 等进阶方向大致解决什么问题

### 建议学习顺序

- 第 1 章 → 第 2 章 → 第 3 章 → 第 4 章 → 第 5 章（严格递进，第 4 章需要前 3 章的概念基础）
- 时间估计：第 1-3 章每章约 30-45 分钟；第 4 章动手约 60-90 分钟；第 5 章速查约 20 分钟
- 第 5 章速查表可复制留存，实际部署时对照使用
