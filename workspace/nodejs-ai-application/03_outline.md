## 学习路径说明

### 前置要求
- 掌握 JavaScript 基础语法（变量、函数、数组、对象、条件判断、循环）
- 至少了解 Promise 的基本概念（若完全不了解，建议先花 1-2 天补充 JS 异步基础）
- 能在终端/命令行中执行基本命令（cd、ls/dir、mkdir）
- 具备基本的英文阅读能力（Node.js 生态以英文文档为主）
- 无需任何 Node.js 经验（本笔记从零开始）

### 学完能做什么
- 理解 Node.js 运行时架构和事件循环的核心原理
- 独立搭建 Node.js 开发环境并管理项目依赖
- 使用 fs/path 模块完成文件读写、目录操作等常见任务
- 使用 http 模块创建基础的 HTTP 服务器
- 使用 Express 框架构建 RESTful API，理解路由与中间件机制
- 使用 async/await 编写清晰的异步代码，避免常见陷阱
- 使用 nodemon、dotenv 等工具提升开发效率
- 了解 Node.js 项目的推荐结构与最佳实践
- 具备继续学习数据库、认证、部署等进阶内容的坚实基础

### 建议学习顺序
| 顺序 | 章节 | 建议时间 | 说明 |
|------|------|---------|------|
| 1 | 第一章：Node.js 初识 | 30 分钟 | 先建立整体认知，不要纠结细节 |
| 2 | 第二章：环境搭建 | 1 小时 | 边看边安装，确保环境可用 |
| 3 | 第三章：模块系统 | 1.5 小时 | 重点理解两种模块写法的区别 |
| 4 | 第五章：文件与路径操作 | 2 小时 | 先做这章再学异步，有具体操作更有感觉 |
| 5 | 第四章：异步编程 | 2-3 小时 | 最核心也最容易卡住，不要追求一次完全理解 |
| 6 | 第六章：事件循环 | 2 小时 | 跟在异步之后，加深对 "为什么这样写" 的理解 |
| 7 | 第七章：Express 入门 | 2-3 小时 | 综合前几章知识，构建真正的 Web 服务 |
| 8 | 第八章：环境配置与最佳实践 | 1.5 小时 | 贯穿项目始终的工具和规范 |
| 9 | 第九章：项目实战 | 3-4 小时 | 动手做项目，巩固所有知识点 |

> **学习建议**：每学完一个章节就动手敲代码，不要只看不写。遇到报错时，学会阅读错误堆栈（error stack）——这是 Node.js 开发者最核心的调试技能。学完本笔记后，建议按第九章的实战项目清单逐项完成，再决定是否进入数据库、认证、部署等进阶方向。
