## 研究计划

### 探索方向
1. new-api 是什么：定位、与 one-api 的关系、核心能力（渠道/令牌/分发/日志/计费）
2. 从零部署：环境准备（服务器、Docker）、Docker 部署、首次启动与登录
3. 日常使用：渠道配置、令牌管理、模型分发、接入第三方客户端（如 OpenClaude/NextChat 等）
4. 常见坑与最佳实践：额度限流、渠道负载均衡、自动禁用、数据备份、升级

### 重点收集
- **核心概念**: 中转站、上游渠道（Channel）、令牌（Token）、模型映射、额度（Quota）、限流（Rate Limit）
- **实战代码**: Docker Compose 配置、环境变量、反向代理（Nginx/Caddy）示例、渠道 API 配置示例
- **常见坑**: 渠道鉴权失败、令牌过期、模型不匹配、Docker 端口冲突、数据库迁移、SSL/域名问题
- **工具链**: Docker、Docker Compose、new-api 管理面板、第三方客户端接入
