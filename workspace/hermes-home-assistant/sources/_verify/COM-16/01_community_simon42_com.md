Ich nutze ha-mcp in Kombination mit Claude Code im CLI.
Die MCP Tools verbrauchen schon über 60k Tokens. Ich kenne mich nicht so damit aus, ob und wie man das auf ein notwendiges Minimum reduzieren könnte, aber das scheint mit unnötig viel.
Gibt es einen einfache Möglichkeit, die Aufwand für die Tools deutlich zu reduzieren??

##  Beitrag von Mercator am 6. Juli 
[ Mercator ](https://community.simon42.com/u/mercator)
[ 6. Juli ](https://community.simon42.com/t/ha-mcp-macht-den-kontext-voll/88707/2 "Beitragsdatum")
Was äußert denn Claude dazu, wenn du ihn fragst?
Nach ein wenig nachspüren:
  1. Chat-Verlauf zurücksetzen (Sofort-Hilfe)


Die Messages schnappen sich aktuell 110k Tokens.
Setz die Session im CLI einfach mit “/clear” zurück (oder Terminal neu starten).
  1. HA-Tools ausmisten


Dein Home Assistant MCP-Server ballert Claude mit stolzen **77 Tools** zu, Claude braucht im Alltag niemals 77 Tools gleichzeitig.
Du musst Filter in deiner MCP-Konfiguration (z. B. claude_desktop_config.json) setzen.
Schließe unbedeutende Domains oder Entitäten aus (z. B. jeden einzelnen Batterie-/Signalstärkensensor, Update-Entitäten, Tracker etc.). Limitiere es am besten über include_domains auf das, was du wirklich per CLI steuern willst (z. B. light, switch, climate).
