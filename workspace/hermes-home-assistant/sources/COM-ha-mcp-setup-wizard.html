Quick Setup — HA Custom Component

Recommended

Runs the full ha-mcp server inside Home Assistant. Works on every Home Assistant installation type — Home Assistant OS, Supervised, Container, and Core.

  1. Install HA-MCP Custom Component from HACS, then restart Home Assistant.
  2. Go to Settings → Devices & Services → Add Integration, search HA-MCP Custom Component, and choose HA-MCP Server.
  3. Submit — creating the entry starts the server.
  4. Copy the connect URL from the entry's Configure screen (a notification points you there; the URL is also printed in the Home Assistant log).
  5. Paste it into your AI client — pick the client below for its exact config.

Need client-specific config, or a different install method (App (add-on), Docker, uvx, or local stdio)? Use the setup wizard below.
