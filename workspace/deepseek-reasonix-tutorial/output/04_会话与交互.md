# DeepSeek-Reasonix 会话与交互

> [!info] 文档定位
> 这是基础功能篇第 4 章。本章解决「进了会话之后怎么操作」的问题：会话怎么存、怎么恢复、斜杠命令有哪些、v1 和 main-v2 到底差在哪、`/init` 记忆怎么用、快捷键怎么按。读完你可以不翻文档地在 TUI 里完成日常会话管理。CLI 全量参数见 [[DeepSeek-Reasonix CLI 完整参考]]，权限模式语义见 [[DeepSeek-Reasonix 权限模式指南]]。

## 一、会话模型

### 会话是什么

Reasonix 里一次「从启动到退出」的持续交互就是一个会话（session）。TUI 模式下，会话把你在其中的每一条消息、模型每轮回复、每次工具调用及其结果都完整记录下来——这是它「可以一直开着跑」的基础：跑得再久，每一步都能回看、能撤销、能恢复。

> [!tip] 大白话
> 把会话想成「一份带执行流水的时间线聊天记录」：不只有你说了什么、agent 回了什么，还有它每调一次工具、每读到什么文件，都按顺序记在里面。所以它才能重放、能对比、能断点恢复。

### 本地存储与 JSONL 转录

会话在本地以 JSONL 转录（transcript）的形式持久化，即每行一条 JSON 记录、按时间追加。转录按时间单调追加、不重写旧行——这个「只追加」原则与前缀缓存的 APPEND-ONLY LOG 设计一致，任何重写旧记录的操作都会破坏缓存命中（命中机制详见第 9 章）。

转录文件可以直接复用：

- `reasonix replay <jsonl>`：把一份转录重放成可读会话；
- `reasonix diff <a> <b>`：对比两份转录的差异，适合排查「为什么这次行为和上次不一样」。

### TUI 顶栏：缓存与 usage

会话运行时，TUI 顶栏会实时显示缓存命中率：`prompt_cache_hit_tokens / (hit + miss)`，逐轮计算。命中率是会话健康度的第一指标——命中越高越省钱（命中输入按未命中的约 10% 计费）。同时配置 `[ui] show_turn_usage = true` 会在每轮显示本次请求的 token 与费用，配置方式见 [[reasonix.toml 配置详解]]。

## 二、会话管理命令

会话管理分「命令行」与「会话内」两层：

| 命令/参数 | 作用 |
|-----------|------|
| `reasonix sessions` | 列出历史会话 |
| `reasonix prune-sessions --days N` | 清理 N 天前的旧会话 |
| `reasonix replay <jsonl>` | 转录重放 |
| `reasonix diff <a> <b>` | 对比两份转录 |
| `-c` / `--continue` | 恢复最近一次会话 |
| `-r` / `--resume [QUERY]` | 打开会话选择器；带子串则按子串模糊恢复 |
| `--copy` | 把某会话复制到可写副本继续，原会话保持只读 |
| 会话内 `/resume` | 会话内恢复/切换历史会话 |
| 会话内 `/switch` / `/tree` / `/branch` | 切换会话 / 查看会话树 / 创建分支 |

示例：

```bash
# 列出历史会话
reasonix sessions

# 清理 30 天前的旧会话
reasonix prune-sessions --days 30

# 恢复最近一次会话
reasonix code -c

# 按子串模糊恢复
reasonix code -r "MCP 调试"

# 在可写副本上继续，不污染原会话
reasonix code --copy
```

> [!tip] 大白话
> `-c` 是「接着上次没聊完的聊」，`-r` 是「翻聊天记录挑一个旧对话」，`--copy` 是「把旧对话复印一份，在复印件上继续改」。三者恢复的都是会话状态，别和文件恢复混为一谈。

## 四、v1 与 main-v2 版本差异（关键澄清）

> [!warning] 版本差异
> main-v2 的 `CLI.zh-CN.md` **未收录** `/init`、`/plan`、`/mode`、`/budget`、`/preset` 等命令——它们存在于 v1 的 `CLI-REFERENCE.md`。反过来，main-v2 强调 `/work-mode`、`/currency`、`/docs`、`/reload`，这些是 v1 没有的新入口。

为什么会有两套：Reasonix 迭代较快，v1 文档与 main-v2 文档的命令列表已经分叉。**教程和速查表只能作为参考，应用内 `/help`、`/keys` 才是实时权威**——你敲的 `/` 后面能补全出什么，就以什么为准。

遇到「命令不存在」的报错，第一反应应该是「版本差异」，而不是「工具坏了」：

1. 在会话内敲 `/help`（或 `/keys`）查看当前版本实际支持的命令；
2. 确认后换用对应命令（例如 main-v2 没有 `/plan`，就改用 `/work-mode` 相关能力）；
3. 需要 `/init` 等 v1 命令时，确认你安装的分支/版本是否包含对应实现。

> [!tip] 大白话
> 把 v1 和 main-v2 想成「同一款软件的两个菜单版本」：菜品大体相同，但有些菜在旧菜单上有、新菜单上被换掉了。你不可能记全两本菜单，直接看店里当天贴的菜单（`/help`）最靠谱。

## 五、/init 与记忆

Claude Code 用 `CLAUDE.md` 存项目指令，Reasonix 的对应物是 `REASONIX.md` / `AGENTS.md`，由会话内 `/init` 生成（`/init [force]` 可强制重生成）。`/init` 会扫描当前项目，把项目结构、关键约定、工作偏好沉淀成记忆文件，之后会话会读取这些记忆文件作为项目指令。

记忆文件在**双模型协同**中角色关键：启用 `[agent] planner_model` 后，规划器（planner）只读 `REASONIX.md`/`AGENTS.md` 记忆加只读研究工具来制定方案，写入工具只交给执行器——记忆就是规划器的「工作简报」（模型与双模型细节见第 7 章）。

除了项目记忆，main-v2 还提供会话内记忆操作：

- `/remember <note>`：把一条笔记写入记忆，适合「记住这个偏好/约定」；
- `/memory`：查看或管理已保存的记忆。

> [!tip] 大白话
> `REASONIX.md`/`AGENTS.md` 就像给 agent 的「入职手册 + 岗位说明」：它不需要你每次重新口头交代项目背景。用 `/init` 生成一次，之后每个新会话都自动带上这份背景。

## 六、快捷键与交互

TUI 的交互快捷键与 Claude Code 高度对齐（PR #6431），熟悉 Claude Code 的用户几乎零成本迁移：

| 快捷键 | 作用 |
|--------|------|
| `Up` / `Down` | 选择器移动 |
| `Ctrl+P` / `Ctrl+N` | 选择器移动 |
| `j` / `k` | 搜索为空时移动（Vim 风格） |
| `Shift+Tab` | 权限模式循环：Ask → Auto → Plan |
| `Ctrl+Y` | 独立切换 YOLO（绕过权限） |
| `Enter` / `Esc` | 选中 / 取消 |
| `y` / `a` / `p` / `n` + 数字 | 审批动作 |
| `y` / `n` | 编辑门控：接受 / 丢弃待定编辑 |
| `u` | 撤销最近自动应用的编辑批次 |
| mac/Linux `Ctrl+V`、Windows `Alt+V` | 粘贴图片（也可用 `/paste-image`） |

> [!tip] 大白话
> `Shift+Tab` 像手电筒的档位切换（常亮 / 自动 / 省电模式），在 Ask / Auto / Plan 之间循环；`Ctrl+Y` 则是独立的「紧急直通开关」，一按直接进入绕过权限的 YOLO 状态。日常建议保持 Ask，需要批量放行再临时切 Auto。

权限模式的完整语义（6 种模式、fail-closed、deny 优先级）见 [[DeepSeek-Reasonix 权限模式指南]]。

## 七、常见坑

1. **命令不存在，多半是版本差异**。v1 与 main-v2 的命令列表不同（如 `/init`、`/plan`、`/budget` 只在 v1 文档），先敲 `/help` 看实时权威。
2. **`/init` 不是生成一次就完**。改了项目结构或约定后，用 `/init [force]` 重生成记忆文件，否则 agent 还抱着旧背景干活。
3. **恢复会话用错参数**。`-c` 只恢复最近一次；要挑历史会话用 `-r [QUERY]`；要保留原会话不动用 `--copy`。
4. **记忆不生效先查文件**。确认项目根有 `REASONIX.md`/`AGENTS.md`，且 `[agent] planner_model` 场景下规划器有读权限。
5. **上下文越滚越大**。v1 可手动 `/compact`；main-v2 依赖 `[agent]` 压缩参数自动处理，参数含义见 [[reasonix.toml 配置详解]]。

## 常见问题

**Q：main-v2 下敲 `/init` 报不存在，是没装对吗？**
A：大概率是版本差异。main-v2 的 `CLI.zh-CN.md` 未收录 `/init`，它属于 v1 命令。以应用内 `/help` 为准。

**Q：`-r` 和 `-c` 有什么区别？**
A：`-c/--continue` 恢复最近一次会话；`-r/--resume [QUERY]` 打开选择器或按子串模糊恢复指定的历史会话。

**Q：会话转录能重放或分享吗？**
A：可以。会话以 JSONL 转录本地落盘，用 `reasonix replay <jsonl>` 重放、`reasonix diff <a> <b>` 对比；转录文件也可移交给同事排查。
