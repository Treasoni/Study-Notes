## 学习路径说明

### 前置要求
- 有 Linux/macOS 终端使用经验，能打开 shell 执行命令
- 理解 PATH、命令行选项、退出码等基本概念
- 有简单的 bash 基础（变量、循环）更佳；无经验也可从第七章起边写边学

### 学完能做什么
- 用 curl / wget / aria2 下载单个与多个文件，并说清三者的选型差异
- 实现断点续传、失败重试与并发下载，应对慢速/不稳定网络
- 用校验和验证下载文件完整性，处理代理与 TLS 证书问题
- 编写健壮的批量下载 bash 脚本（`set -euo pipefail` + 数组 + 错误日志）
- 独立排查常见下载失败（退出码、权限、404 假成功、文件名转义等）

### 建议学习顺序
- 第一章 → 第二章 → 第三章：工具基础，建立最小可用能力（约 1.5-2 小时）
- 第四章 → 第五章 → 第六章：可靠性进阶（续传 / 并发 / 重试 / 校验 / 安全）（约 2-2.5 小时）
- 第七章 → 第八章：批量脚本与健壮性（约 1.5-2 小时）
- 第九章：综合实战，产出最终可复用脚本（约 1 小时）
- 建议边学边在终端验证每个命令，不跳过代码示例
