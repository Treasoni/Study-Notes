## 章节详情

### 第 1 章 什么是虚拟机：从「电脑里的电脑」说起

- **篇幅**：中，约 800–1200 字
- **覆盖要点**：VM 定义与生活比喻、Host/Guest/Hypervisor 三角色、Type 1/Type 2 定义与代表产品、典型用途
- **素材引用**：`05_cloud_google_com.md`（VM 定义/架构/用途）、`03_docs_oracle_com.md`（Host/Guest/VM 术语）、`11_www_techtarget_com.md`（Type 1/2 架构与产品归类）
- **步骤/命令示例**：无（仅文字版分层示意：应用 → 客户机 OS → Hypervisor → 宿主硬件）
- **表格**：有——Type 1 vs Type 2 对照表（部署位置 / 代表产品 / 资源开销口径按红线修正）
- **小节结构**：
  - 1.1 一台用软件造出来的「电脑」：定义 + 比喻 + 它跑在哪
  - 1.2 三个角色正名：宿主机 Host / 客户机 Guest / Hypervisor（旧名 VMM）
  - 1.3 Hypervisor 的两种形态：Type 1（裸机）与 Type 2（托管），各举实例
  - 1.4 典型用途：学新系统、隔离试验、跑不兼容旧软件、一台当多台用
- **写作红线**：不得采用「Type 2 比 Type 1 更小更快、资源更少、单机承载更多」（`02_deep_research.md` §四.1）；统一口径 = Type 2 跑在宿主 OS 之上、多一层转发路径、宿主 OS 是共同关注点。Hypervisor 作用用「把宿主 CPU/内存/存储/网络切块分池给客户机」表述。一句话带过「虚拟化 ≠ 云」。

### 第 2 章 虚拟机 vs 容器 vs WSL2：三种「装系统」的思路

- **篇幅**：中，约 900–1300 字
- **覆盖要点**：系统级 vs 应用级隔离、VM 自带完整 OS、容器共享宿主内核、WSL1/WSL2 定位、互补关系
- **素材引用**：`05_cloud_google_com.md`、`12_baeldung_cn.md`（容器/VM 对比）、`13_learn_microsoft_com.md`（官方逐项对比）、`07_learn_microsoft_com.md`（WSL1 vs WSL2）
- **步骤/命令示例**：无
- **表格**：有——VM / 容器 / WSL2 对比表（隔离单位 / 内核 / 启动速度 / 更新方式 / 是否可跑异构 OS / 典型场景）
- **小节结构**：
  - 2.1 核心分水岭：搬一整套「带家具的房子」 vs 只打包自己的行李、共享水电
  - 2.2 逐项对比：隔离强弱、重量、启动、更新（13 的「VM 补丁重、容器重建镜像即更新」是第 8 章伏笔）
  - 2.3 容器引擎不是 Hypervisor（口径统一，红线）
  - 2.4 WSL1（系统调用转换层，非 VM） vs WSL2（微软托管的轻量实用 VM，跑真 Linux 内核）
  - 2.5 互补：容器经常跑在虚拟机里（云上常见架构）
- **写作红线**：不采用「容器引擎是专门化 Type 2 hypervisor」（§四.2），统一「容器共享宿主内核、无 hypervisor」。WSL2 与 VirtualBox/Hyper-V 共存结论较旧，标注「以当前版本实测为准」（§四.5）。

### 第 3 章 虚拟硬件与虚拟磁盘：这台「电脑」由哪些文件组成

- **篇幅**：中，约 800–1200 字
- **覆盖要点**：VM = 一组参数 + 状态、虚拟硬件清单、虚拟磁盘 = 宿主上的镜像文件、动态 vs 固定分配、磁盘格式归属
- **素材引用**：`05_cloud_google_com.md`、`03_docs_oracle_com.md`、`10_www_makeuseof_com.md`（磁盘格式——只取归属/生态）、`06_knowledge_broadcom_com.md`（稀疏盘特性）
- **步骤/命令示例**：无
- **表格**：有——虚拟磁盘格式归属表（VDI / VMDK / VHD / VHDX → 所属生态）
- **小节结构**：
  - 3.1 VM 本质是「参数 + 状态」：硬件设置（内存/CPU/网卡/磁盘）在配置文件里，真正的「硬盘」是镜像文件
  - 3.2 虚拟硬件与加速基础：Intel VT-x / AMD-V
  - 3.3 虚拟磁盘：镜像文件、动态增长（稀疏）vs 固定大小（「饭卡」比喻）
  - 3.4 磁盘格式只讲归属：VDI=VirtualBox 开源、VMDK=VMware、VHD/VHDX=微软生态
  - 3.5 为什么「磁盘文件是普通文件」很重要：可复制/移动/备份，是快照与瘦身的认知基础
- **写作红线**：磁盘格式**只写归属与生态**，不写「XX 比 XX 快/慢」的绝对性能排序（§四.3）；可操作建议用「长期使用选宿主原生格式更省心」。每个概念给「是什么 / 为什么用 / 一个坑」三件套。埋「磁盘越用越胖」伏笔（第 9 章展开）。

### 第 4 章 快照：虚拟机的「时光机」

- **篇幅**：短，约 400–700 字
- **覆盖要点**：快照定义、何时拍、恢复 vs 删除语义、快照 ≠ 备份、链膨胀
- **素材引用**：`02_docs_oracle_com.md`（快照机制）、`12_baeldung_cn.md`（回滚语义）、`06_knowledge_broadcom_com.md`（删快照是磁盘操作的前提）
- **步骤/命令示例**：无（一段「拍快照 → 玩坏 → 一键回滚」的示意流程）
- **表格**：无
- **小节结构**：
  - 4.1 快照是什么：VM 设置记录 + 磁盘差异镜像（differencing image），运行中拍摄还含内存状态
  - 4.2 什么时候拍：打补丁、装软件、改配置前当「后悔药」
  - 4.3 恢复 vs 删除：恢复 = 整机回滚、其后改动丢失；删除快照只释放磁盘、可能较慢
  - 4.4 两个坑：快照链膨胀（差异镜像只记增量）；「快照不是备份」
- **写作红线**：差异镜像原理讲一句话即可，不深挖 delta 链实现（§六.4）。范围声明：**克隆（Clone）** 无素材步骤，本笔记不展开（如需另补源）。埋钩子：第 6 章做真实「拍 → 回滚」演示。

### 第 5 章 动手 · VirtualBox（上）：安装、建机、装第一个系统

- **表格**：无（向导步骤用编号列表即可）
- **小节结构**：
  - 5.1 动手前准备：安装 VirtualBox、备一份系统 ISO（VBox 不提供系统/许可）、检查 VT-x/AMD-V、留足磁盘与内存

- **素材引用**：`13_learn_microsoft_com.md`（何时用 VM/容器，官方口径）、`08_www_cnblogs_com.md`（四方案选型，社区经验）、`07_learn_microsoft_com.md`（WSL2 定位）、`05_cloud_google_com.md`

## 学习路径说明

### 前置要求

- 会用 Windows 桌面软件（能走「下一步」式的安装向导即可）
- 不需要任何虚拟化或编程基础；术语首次出现一律给中文口语化解释
- 建议硬件准备：约 30–60 GB 空闲磁盘 + 一台支持 VT-x/AMD-V 的电脑（第 5 章教怎么查/开）

### 学完能做什么

- 能向别人解释虚拟机、Hypervisor、虚拟磁盘、快照，说清 VM 与容器、WSL2 的本质区别
- 能在 VirtualBox 里从零建一台虚拟机：装系统、装增强功能、打快照、回滚、切换 NAT/桥接等网络模式
- 了解 VMware Workstation 装 Windows 11 的特殊点（vTPM / 加密）
- 知道什么时候该用虚拟机、Windows 桌面四套方案怎么选，能处理「磁盘越用越胖」「VT-x 没开」「宿主被卡死」等入门最常见的坑

### 建议学习顺序

- 第 1–4 章顺序阅读（约 40 分钟）：先把概念地图建起来，再动手
- 第 5–7 章边读边做（约 1–1.5 小时含动手）：至少把 VirtualBox 一条线完整做完；VMware 章可作为对照或整章跳过
- 第 8–9 章实操后再读（约 30 分钟）：作选型与排障速查
- 整条线含动手约 2.5–3.5 小时，可分 2–3 次完成
