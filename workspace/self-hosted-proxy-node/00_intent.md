## 研究计划

### 探索方向

1. **概念层**：节点、服务端/客户端、入站/出站、协议与传输、TLS 与伪装、订阅、流量走向。
2. **服务端方案选型**：Xray-core、sing-box、3X-UI、Hiddify Manager、Remnawave、Marzban、NaiveProxy 的定位与取舍。
3. **协议现状**：VLESS + Reality/Vision、Hysteria2、TUIC v5、Shadowsocks-2022、AnyTLS；已淘汰路线及其原因。
4. **VPS 准备与系统硬化**：系统选择、SSH 公钥、防火墙、fail2ban、自动安全更新、BBR。
5. **首个节点搭建**：内核安装、入站配置、证书/伪装参数、客户端对接与连通校验。
6. **运维与演进**：多节点与配置同步、备份迁移、监控、与组网层（Tailscale）的衔接。

### 重点收集

- **核心概念**: 节点、入站/出站、协议 vs 传输、Reality / Vision、端口跳跃、订阅机制
- **实战代码**: Debian 12 / Ubuntu 22.04 上的安装与配置片段、Reality 四参数配置、客户端导入步骤、转发与 BBR 调优
- **常见坑**: 脏 IP 与风控、单一协议单点、管理面板裸暴露、Reality 四参数不匹配、单机方案在多机场景的配置漂移
- **工具链**: sing-box、Xray-core、3X-UI、Hiddify Manager、Remnawave、mihomo/Clash 系客户端
