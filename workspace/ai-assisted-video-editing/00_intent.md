## 研究计划

### 探索方向（P1 探测后收敛为正式方向）
1. AI 助手能力盘点：Codex / Claude Code 等 agent 能接管哪些剪辑环节（脚本化批处理 vs 创意剪辑），边界在哪
2. 工具链与脚本化方案：FFmpeg、yt-dlp、字幕与语音识别工具、剪辑软件自动化脚本的组合用法
3. 人机协作工作流：从需求 → 生成脚本 → 预览确认 → 批量执行的完整闭环与常见工程模式

### 重点收集
- **核心概念**: 无损剪切/拼接（stream copy）、容器与编码、时间轴精度、字幕提取与烧录、批处理与幂等性、AI agent 工具调用边界
- **实战代码**: FFmpeg 剪切/拼接/转码/抽帧/加字幕/自动卡点命令模板；用 AI 助手落地这些命令的交互模式
- **常见坑**: 音视频不同步、编码/容器不兼容、二次编码画质损失、中文路径与空格、素材预览确认成本、AI 生成错误命令的兜底
- **工具链**: FFmpeg、yt-dlp、Whisper 等字幕/语音工具、剪映/PR 的脚本与导出生态、Codex CLI、Claude Code
