# 第3章 实名与 ICP 备案——大陆上线的硬门槛

上一章选好后缀、付完钱后，域名在「名义上」属于你了。但要让网站在大陆正式上线，还横着两道硬门槛：**域名实名认证**与 **ICP 备案**。实名不通过，域名连解析都会被暂停；备案没做，解析到大陆服务器的流量会被接入商监测后直接阻断。本章回答三个问题：你的场景到底要不要备案？要备的话得满足哪些条件、大致走什么流程？各种「免备案」的说法里，哪些成立、哪些是误区。

## 3.1 先判场景：要不要备案

要不要备案，关键只看**源站服务器的物理位置**——即网站程序实际跑在哪里的机房。解析到**中国大陆服务器**的网站/App，必须备案；域名放**境外服务器**则无需备案[^c3-1]。这里有两个常见的「想当然」要纠正：

- **跟域名在哪注册无关**。无论域名是在阿里云、腾讯云还是海外注册商买的，决定备案与否的都是服务器位置。
- **跟前端套了什么无关**。域名解析到 CDN、套了层加速，并不改变源站物理位置——这点 3.6 会专门展开。

之所以这么硬，是因为未备案解析到大陆服务器，会被接入商监测并阻断访问[^c3-2]。所以「先定部署地、再谈备不备案」是合规链路的第一分叉：大陆源站要快，组合是「大陆服务器 + 备案 + 国内 CDN / Cloudflare 中国版」；想免备案又要海外快，则用「海外或香港服务器 + Cloudflare 全球版」，代价是大陆访问的延迟与稳定性波动[^c3-3][^c3-4]。完整取舍速查见第 7 章，这里先建判断框架。

> [!tip] 大白话：把「备案」想成给实体店办营业执照
> 营业执照归**店铺所在地**的市场监管部门管，不归招牌印刷厂管。服务器就是你的「店铺所在地」，域名只是「招牌」。招牌在哪做的、挂了几层广告牌（CDN）都不影响——只要店开在大陆，就得办大陆的执照。所以判断口诀只有一句：**源站物理位置在大陆，就要备案。**

## 3.2 域名实名认证

实名认证是备案的前置，也是独立于备案的一道关卡：凡在大陆注册商注册的域名，都需要做实名。材料按主体类型区分[^c3-5]：

- **个人**：身份证彩色件。
- **企业**：营业执照；填写的联系人须为个人（建议直接填法人）。

实名审核通常要 **1~3 个工作日**。这里要特别留意一个后果：**实名失败时，域名会进入 Serverhold 状态（暂停解析）**，表现为域名在 DNS 上「查不到」「解析不了」；实名通过后约 **48 小时**才恢复[^c3-5]。也就是说，实名没搞定，域名就是「锁住的门牌」，解析、建站都无从谈起；所以实操要「先行」——注册完立刻提交。

> [!tip] 大白话：把「实名」想成给域名办门禁卡
> 大陆注册商发的域名就像一张进楼的门禁卡，实名就是「登记身份证」。登记没通过，物业（注册局）会把卡冻结——这就是 Serverhold，谁拿这张卡都刷不开门，域名解析直接停摆。登记通过了，卡解锁，约 48 小时后恢复正常出入。

另外，实名信息要为备案服务：域名实名的「四要素」（持有者名称、证件类型、证件号码等）必须与备案主体一致[^c3-6]——用 A 的身份实名、却想用 B 的主体备案，会在这里卡住。

## 3.3 备案前置条件清单

不是「想备就能备」。提交前，域名得先过一串核验，对照下面清单可提前筛掉绝大多数返工[^c3-6]：

- **后缀在工信部批复列表内**。只有工信部批复过的顶级域才能在大陆备案，`.org` 等未批复后缀不可用（2.4 选购红线已提）。
- **注册商是批复机构**。域名所在注册商须是具备大陆备案核验资质的批复机构。
- **主域名到期时间须 > 45 天**。临期域名不能备案。
- **实名四要素与备案主体一致**。承接 3.2。
- **注册在「国际站/海外账户」的域名要先转回**。以阿里云为例，在阿里云国际站注册的域名，须转入中国内地注册商并完成实名后，才能用于备案[^c3-6]。

> [!tip] 大白话：把「到期 > 45 天」想成签长期租约
> 备案相当于跟管局签一份「长期摊位合同」，而域名到期就是租约到期。合同只剩一个多月就到期，管理方自然不愿给你办长期手续——万一你域名断了，备案就悬空了。所以先确保域名租约够长（> 45 天），再去办手续。

> 各省管局对上述条件的执行细节可能存在差异，提交前以接入商和当地管局的**最新要求**为准。

## 3.4 大陆备案流程概览

先说清一个类型区分：大陆的「备案」分两类——面向**非经营性**网站（个人博客、展示页、绝大多数自建服务）的是**备案制**，在接入商处提交即可；面向**经营性**网站（电商、收费平台等）的须办理 **ICP 许可证**，门槛高得多，通常超出个人自建服务的范围[^c3-2]。本书后续提到的「备案」，如无特别说明都指前者。

非经营性备案本身不是你去管局提交，而是通过**接入商**代办（服务器买在哪家云厂商，就在哪家提交）。准备材料大致是[^c3-5][^c3-2]：

- **主体材料**：个人身份证 / 企业营业执照，以及经办人（联系人）身份信息。
- **域名材料**：已完成实名的域名，且满足 3.3 全部条件。
- **服务器归属**：备案通常要求服务器资源也在同一接入商名下或可关联核验。
- **核验环节**：按接入商要求做人脸核验或幕布拍照，各地流程略有不同。

几个容易混淆的规则，一并记牢[^c3-2][^c3-6]：

- **只备主域名，子域名免额外备案**。备了 `example.com`，`blog.example.com`、`app.example.com` 直接可用，不用逐个备。
- **换接入商要重办「接入备案」**：从阿里云迁到腾讯云，不是把原备案「搬过去」，而是在新接入商重新走一次。
- **未备案别硬解析到大陆服务器**，接入商监测到会阻断访问。
- **备案以域名为对象**：阿里云代备案不支持只给 IP 备案[^c3-6]。

> [!tip] 大白话：把「只备主域名」想成办大楼总门牌
> 备案相当于给整栋楼办一个总门牌号，楼里的每个房间（子域名）共用这个门牌，不用每间房再单独办一个。所以备了 `example.com`，下面开多少个子域都覆盖了。而「换接入商」就像换物业——换了物业公司，哪怕还是同一家店，也得在新物业那儿重新登记一次（接入备案）。

顺带提醒：备案通过不等于访问无忧——它解决的是「合规」，社区经验里备案站点同样可能遇到访问质量波动，海外域名在大陆「能解析」也不等于「体验好」[^c3-4]。这些第 7 章会系统梳理。

## 3.5 不备案的路径：境外部署对照

若用户不在大陆、或试验项目不追求大陆访问速度，可把源站放**境外**合法绕开备案。对照如下：

| 决策维度 | 大陆备案路径 | 境外免备案路径 |
| --- | --- | --- |
| 源站位置 | 中国大陆服务器 | 海外/香港服务器 |
| 备案要求 | 必须 ICP 备案 | 免备案 |
| 大陆访问速度 | 快（配合国内 CDN / CF 中国版） | 一般，受跨境链路 QoS 波动影响 |
| 海外访问 | 视线路而定 | 快（配 Cloudflare 全球版） |
| 合规成本 | 实名 + 备案，周期较长 | 无大陆备案成本 |

判断依据仍是 3.1 那条：**源站物理位置在境外，就不触发大陆备案义务**。香港服务器是常见的「中间选项」——物理上算境外、免备案，但对大陆的访问延迟通常比纯海外机房好一些，不过仍属跨境链路，稳定性不保证[^c3-3][^c3-4]。

再强调一次：「免备案」不等于大陆一定能流畅打开——它省的是**合规手续**，省不掉**跨境网络的不确定性**。域名被墙与 IP 被封是两种阻断，第 7 章再细分。

## 3.6 「套 CDN 免备案」误区提示

网上流传一种说法：「我给网站套个境外 CDN（比如 Cloudflare），把域名解析到 CDN 上、不直接落大陆服务器，是不是就不用备案了？」

**结论：这是误区。** 判定标准仍是 3.1 那条——**源站物理位置**。只要源站还在大陆服务器上，即使解析指向境外 CDN、用户流量「看起来」先到 CDN，依然触碰政策红线[^c3-3]。

> [!tip] 大白话：CDN 只是给店换了身马甲
> 把 CDN 想成给店铺换了个更气派的前台门面。门面（CDN）换了，可店（源站服务器）还是开在大陆原地。检查的人查的是**店在哪儿**，不是门面长啥样。所以大陆源站套境外 CDN，等于穿着马甲开店，该办的执照一样不能少。

那 Cloudflare 全球版的正确打开方式是什么？它对应 **3.5 的境外路径**：源站本身在海外/香港，配 CF 全球版做加速防护。反过来，大陆源站想用 Cloudflare，走的是**备案 + Cloudflare 中国版（京东云运营）**这条路[^c3-3]。一句话收束：**先看源站在哪，再谈套 CDN**——CDN 是加速工具，不是合规后门。完整决策速查表在第 7 章 7.1。

## 本章小结

- **判场景先于一切**：要不要 ICP 备案，看的是源站服务器物理位置，不是域名注册地、也不是前端 CDN。
- **实名是独立前置关**：个人用身份证彩色件、企业用营业执照且联系人填个人；实名失败会进 Serverhold（暂停解析），通过后约 48 小时恢复，审核通常 1~3 个工作日。
- **备案有硬性前置条件**：后缀须工信部批复（`.org` 等不行）、注册商须为批复机构、主域到期须 > 45 天、实名四要素与备案主体一致；国际站账户买的域名要先转回内地注册商。
- **流程要点**：非经营性走备案制（经营性须 ICP 证）；只备主域名、子域免备；换接入商要重新办「接入备案」；备案以域名为对象，不能只备 IP。
- **免备案与误区要分清**：源站放海外/香港可合法免备案，代价是大陆访问延迟与 QoS 波动；「大陆源站套境外 CDN 免备案」是误区——要么源站出境，要么备案后走国内/CF 中国版加速。

下一步，实名和备案搞定后，域名才真正进入「可自由配置」的状态。第 4 章我们来看注册商与解析商怎么分工、如何把解析托管出去并做子域委派，以及域名转移和账号安全基线。
