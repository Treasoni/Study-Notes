# 第2章 域名选购与注册——后缀怎么选、钱花在哪

第1章让你看懂域名怎么工作、一次解析怎么走完全程。这一章回到最实际的第一个决定：后缀（TLD）选什么、钱到底花在哪。核心是拆穿「首年超低价」的话术——域名是按年续费的长生意，真正的价格锚点是**续费价**，不是广告里那个醒目的首年数字。

## 2.1 价格真相：首年与续费要同看

注册商几乎都用「新用户首年价」来拉新，因为域名本质上是每年都要续费的产品。把首年价和续费价并排放在一起，很多「捡便宜」的错觉会立刻消失。下面是一份注册商资讯给出的常见后缀报价：

> 不同平台/时间点报价，仅作量级参考。

| 后缀 | 首年价（¥） | 续费价（¥） | 报价口径 |
|---|---|---|---|
| .com | 85 | 95 | 聚名资讯，2026-07[^c2-1] |
| .cn | 38 | 42 | 聚名资讯，2026-07[^c2-1] |
| .net | 99 | 109 | 聚名资讯，2026-07[^c2-1] |
| .xyz | 15 | 98 | 聚名资讯，2026-07[^c2-1] |
| .top | 28 | 68 | 聚名资讯，2026-07[^c2-1] |
| .shop | 18 | 118 | 聚名资讯，2026-07[^c2-1] |
| .icu | 22 | 98 | 聚名资讯，2026-07[^c2-1] |

另一家注册商新网（2026-06）口径略不同：.com 首年约 ¥68–129、多数次年 ¥139+；.cn 首年约 ¥28–55；.xyz/.site 首年约 ¥19–39[^c2-2]。两家同为「首年便宜、续费上涨」的规律，但具体数字随平台活动浮动，连 .com 的续费价都不一致——这恰恰说明：**不要拿 A 平台的首年价比 B 平台的续费价，要在同一平台内对比首年、续费两列**。

[!tip] 大白话
把「首年超低价」想成超市开业的鸡蛋特价——今天便宜是为了让你以后常来。域名按年续费，注册商赚的是后面每年的钱。所以别被首年价勾走，同一平台的续费价才是你的真实持有成本。

[!warning] 易错点
只盯首年价最容易踩的坑，就是低价后缀的续费跳涨：上表里 .xyz 首年 ¥15、续费 ¥98（约 6.5 倍），.shop 首年 ¥18、续费 ¥118。买之前请先想清楚：这个域名你打算用几年？

## 2.2 选型决策：长期品牌 vs 短期试验

基于上面的价格规律，选购逻辑其实只有两条路：

- **长期品牌 / 正式项目**：优先 .com / .cn / .net，注册后**打开自动续费**。这类后缀续费价平缓、认知度高，自动续费能避免忘了续费导致域名停止解析[^c2-3]。.cn 首年通常最便宜（且是国内建站首选之一），.com 通用性最好。
- **短期试验 / 临时演示**：.xyz / .shop / .icu 这类首年极低的后缀可以一用——做验证、跑通流程、临时演示都合适。第二年续费大涨时，直接弃用换新也不心疼。

[!warning] 易错点
「低价后缀 + 长线运营」是最不划算的组合：你会为第 2 年起的高续费买单，或被迫迁移域名。下单前，先在同一平台把「首年 + 续费」两列一起看，再决定这单属于长期还是短期[^c2-1][^c2-2]。

## 2.3 注册商职责与后续依赖

买域名不是「一手交钱一手交货」的一次性买卖，而是和**注册商**建立长期关系：注册、实名、续费、转移、以及（大陆场景的）备案核验，后续全都挂在注册商后台。选注册商 = 选未来几年所有域名操作的入口，别只看谁家首年价低。

同时要建立一个重要心智：**注册商 ≠ 解析商**，二者可以分离，而且分离是常态——域名留在注册商 A，DNS 解析托管交给解析商 B（DNSPod、阿里云云解析等）[^c2-4][^c2-5]。

[!note] 核心概念
注册商负责「这域名归谁、有没有续费、能不能转走」，管的是所有权生命周期；解析商负责「把域名翻译成哪台服务器的 IP」，管的是使用。第 4 章会专门讲怎么把两者拆开、把解析托管到更顺手的地方。

[!tip] 大白话
把注册商想成「房管局」——登记这套域名产权归谁；解析商想成「快递分拣中心」——负责把门牌号（域名）翻译成具体地址（IP）。买房在房管局过户，但快递怎么送是分拣中心的事，两者可以不是同一家。

## 2.4 大陆建站的后缀红线：先想部署地，再选后缀

如果你的网站/服务要部署在**中国大陆的服务器**上，选后缀前必须先查一道硬门槛：后缀必须在工信部批复列表中，注册商也必须是批复机构——否则**备案核验过不了**。一个典型例子是 .org：它虽然是国际通用后缀、看起来很「正经」，但不在工信部批复列表内，**不能用于大陆备案建站**[^c2-3]。

[!tip] 大白话
把工信部的批复列表想成「商场可入驻品牌名单」——后缀再出名，不在名单上就不能在这家商场开店。大陆建站就是这家商场，所以 .org 进不了大陆备案这道门。

所以选购的先后顺序应当是：**先决定源站放哪（部署地）→ 再倒推要不要备案 → 最后选后缀与注册商**。若源站放在境外（海外/香港服务器），则无需大陆备案，后缀选择更自由——这部分判断标准与代价，第 3 章会详细展开。

## 本章小结

- 域名的真实成本看**续费价**，首年低价只是拉新话术；同一平台内把「首年 + 续费」两列并排看。
- 低价后缀（.xyz/.shop/.icu）首年极便宜但续费常大涨，适合短期试验；长期品牌选 .com/.cn/.net 并开自动续费。
- 注册商管所有权生命周期，解析商管解析，二者可以分离（第 4 章展开）。
- 大陆建站先查部署地：源站在大陆，后缀必须在工信部批复列表，.org 不在其中、无法大陆备案。
