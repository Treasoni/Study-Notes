## 研究计划

### 探索方向
1. 域名与 DNS 原理（域名层级、解析过程、常见记录类型）
2. 域名注册与解析配置（选购、注册商/托管、DNS 记录、CDN/HTTPS 证书）
3. 域名实战接入自建服务（Nginx/Caddy 反向代理、DDNS、内网穿透场景）

### 重点收集
- **核心概念**: 域名层级（TLD/二级/子域）、DNS 解析链路与缓存、记录类型（A/AAAA/CNAME/MX/TXT/NS/TTL）、CDN 与证书
- **实战代码**: 购买后解析配置示例、DNS 托管切换、HTTPS 证书申请、反代配置片段、DDNS 工具配置
- **常见坑**: DNS 传播延迟、CNAME 与 CDN/根域冲突、国内 ICP 备案限制、动态 IP 与 DDNS 抖动、证书自动续期
- **工具链**: 注册商/解析商（如 Cloudflare、阿里云、DNSPod）、certbot/Caddy、ddns-go、cloudflared/tailscale
