# 第四章 AI 内容生产（二）：FunClip 本地智能剪辑与 ShortGPT 停更参考

> 本章定位：第 3 章讲了 MoneyPrinterTurbo 如何「从零做出一条片」，本章补上内容生产流水线的另一半——「对已有素材的精细剪辑」，同时处理两个「不做推荐」的对象：已停更的 ShortGPT，以及素材/脚本管理的开源空白。

## 4.1 FunClip：ASR 驱动的本地智能剪辑

FunClip（仓库 `modelscope/FunClip`，~6.2k★，v2.2.1 于 2026-09-01）是 ModelScope 出品的本地智能剪辑工具。它的核心卖点不是「加特效」，而是把剪片子从「逐帧拖时间轴」变成「在文稿上勾选要保留的句子」。[^c4-1]

[!tip] 大白话
把 FunClip 想成一位「听稿剪辑师」：给它一段音视频，它先不剪，而是把每句话是谁说的、说了什么，转成一份带时间码的文稿；你在文稿上勾选要保留的句子，它就自动把对应画面片段拼出来。剪辑从「拖进度条找切割点」变成「对着文字勾句子」，零基础也能上手。

工作链路：输入音视频 → FunASR 语音识别（Paraformer / SeACo / CAM++ 等模型）→ 输出带时间戳的文本与说话人标签 → 按文本片段或按说话人切段 → 勾选/排除 → 导出剪辑结果。v2.2.1 起内置 Pillow 字幕渲染，识别后可直接把字幕烧进画面，省掉外挂字幕这一步。[^c4-1]

三个使用要点：

1. **基础能力可纯离线**：ASR 识别、按句/按说话人切段都在本地完成，素材不出本机，无云端 Key 依赖。
2. **可选 LLM 剪辑（云端）**：新版支持 TwelveLabs 的 Pegasus 模型做「结合画面 + 音频」的语义剪辑——注意这是云端服务，走这条路径就不再是纯离线。[^c4-1]
3. **资源边界要看清**：官方未给 CPU/显存硬指标；基础功能仅需 Python 即可跑，但 Whisper 时间戳识别需要较大显存。选型时把「要不要本机 Whisper」当作关键分叉。[^c4-1]

### 4.1.1 安装与启动

pip 安装后直接起 Gradio 本地界面（首次运行会自动拉取模型权重）：

```bash
# 安装
pip install -U funclip

# 启动 Gradio 本地界面
python funclip/launch.py
```

启动后按提示打开 Gradio 地址即可上传素材操作。许可要分两层看：源码 MIT（可商用、可闭源），但底层**模型权重各有各的授权**，不等于随源码一并 MIT 授权。[^c4-1]

[!tip] 大白话
把「源码 MIT」与「模型权重各自授权」想成工具与耗材分离：工具箱（代码）开源随便用，但里面的钻头（训练好的模型）是各厂家单独借你的。改代码不受限，商用前却要把每个模型单独过一遍授权，不能因为仓库标了 MIT 就默认全部可商用。

## 4.2 与 MoneyPrinterTurbo 的分工

FunClip 常被误当成第 3 章 MoneyPrinterTurbo 的竞品，其实两者互补：

| 维度 | MoneyPrinterTurbo | FunClip |
|---|---|---|
| 输入 | 主题 / 文案 | 已有音视频素材 |
| 产出方式 | 从零批量成片 | 对素材精细剪辑 / 二次创作 |
| 典型场景 | 每天批量出 9:16 口播视频 | 把长直播 / 录播剪成多条短视频切片 |

对真实经营者更顺的路径是：批量口播用 MoneyPrinterTurbo；把已有的长内容（直播回放、访谈、课程）切成短视频切片时用 FunClip。两条链路互补，合起来才覆盖完「内容生产」环节。

## 4.3 ShortGPT：停更的参考样本

ShortGPT（仓库 `RayVentura/ShortGPT`）曾是 AI 短视频自动化框架的代表，~7.9k★、MIT。但它最后 push 停在 2025-02-10，到盘点时约 19 个月无提交，判定为停更。[^c4-2]

[!tip] 大白话
把停更项目想成一处停工工地：图纸和框架都还在，参观能学到设计思路，但没人继续施工，水电（依赖、浏览器适配）迟早出问题。把生产依赖押在它身上，等于把店开在停工工地上。

四维打分下它的结局很典型：协议没问题（MIT），但「维护活跃度」这一维归零。它内部的短视频脚本/编辑架构思路仍有参考价值，所以只作历史与架构参考，不作生产依赖——这是本笔记少数「明确劝退选型」的对象。

## 4.4 显性缺口：素材与脚本管理

第 1 章预告过两个开源缺口之一「官方数据分析能力」（第 6 章展开）；本章补上内容生产侧另一个隐性缺口——**素材与脚本管理**。你很难找到一个开源工具专门管「选题脚本库 + 已购素材资产 + 成片归档」；这个环节开源接近空白，商业 SaaS 主导。能部分缓解的是第 3 章 MoneyPrinterTurbo 内置的 Pexels/Pixabay/Coverr 免费素材源，以及第 5 章 AiToEarn 的 Create Agent（批量生成素材），但「管素材」本身仍无成熟开源方案——落地前先想清楚这块要不要用轻量表格/网盘自行顶上。

## 本章小结

- FunClip 基于 FunASR（Paraformer/SeACo/CAM++）做本地智能剪辑，把「剪视频」变成「对着 ASR 文稿勾句子」，v2.2.1 起内置 Pillow 字幕渲染。
- 部署边界：`pip install -U funclip` + `python funclip/launch.py` 起 Gradio；基础功能纯离线且仅需 Python，Whisper 时间戳需大显存；源码 MIT 但模型权重各自授权。
- FunClip 与第 3 章 MoneyPrinterTurbo 互补：前者精剪已有素材，后者从零批量成片。
- ShortGPT 已停更（2025-02 后约 19 个月无提交），仅作架构参考，不作生产依赖。
- 素材/脚本管理环节开源接近空白、商业 SaaS 主导，属显性缺口，需自行用轻量方案顶上。

下一章进入一体化视角：对比「一个 AiToEarn 搞定生产→发布」与「MoneyPrinterTurbo + social-auto-upload 纯离线组合」两条路线，并核实它「自部署 ≠ 离线」的云依赖边界。
