#  Building Misskey using Docker Compose 
This guide explains how to set up Misskey using Docker Compose.
Danger
Do not recreate the database with the domain/hostname of the server once you have started using it!
前提条件
  * Make sure Docker and Docker Compose are installed on your system. 


## [Clone the Repository](https://misskey-hub.net/en/docs/for-admin/install/guides/docker/#clone-the-repository)

```
git clone -b master https://github.com/misskey-dev/misskey.git
cd misskey
git checkout master

```

## [Configuration](https://misskey-hub.net/en/docs/for-admin/install/guides/docker/#configuration)
The following commands will copy the various config files from examples to their actual config location.

```
cp .config/docker_example.yml .config/default.yml
cp .config/docker_example.env .config/docker.env
cp ./compose_example.yml ./compose.yml

```

Please edit `default.yml` and `docker.env` file as per the description. Also edit `compose.yml` as needed. (If you want to change the port etc.)
## [Build & Initialize](https://misskey-hub.net/en/docs/for-admin/install/guides/docker/#build-initialize)
The next set of commands will build Misskey image and perform database initialization. This will take some time.

```
sudo docker compose build
sudo docker compose run --rm web pnpm run init

```

## [Startup](https://misskey-hub.net/en/docs/for-admin/install/guides/docker/#startup)
Congraturations! You can launch Misskey with the following command.

```
sudo docker compose up -d

```

GLHF✨
## [Updating Misskey](https://misskey-hub.net/en/docs/for-admin/install/guides/docker/#updating-misskey)
Warning
When updating, be sure to check the [release notes](https://github.com/misskey-dev/misskey/blob/master/CHANGELOG.md) and review any changes and whether additional steps are required (usually none) in advance.

```
git stash
git checkout master
git pull
git submodule update --init
git stash pop
sudo docker compose build
sudo docker compose stop sudo docker compose up -d

```

It may take time depending on the update content and the size of the database.
## [How to execute CLI commands?](https://misskey-hub.net/en/docs/for-admin/install/guides/docker/#how-to-execute-cli-commands)

```
sudo docker compose run --rm web node packages/backend/built/tools/foo bar

```
