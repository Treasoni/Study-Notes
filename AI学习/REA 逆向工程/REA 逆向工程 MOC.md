# REA 逆向工程 MOC

> [!summary] 一句话看懂
> **REA（Reverse Engineer Anything）** 是一个 **MCP server + CLI**（npm 包 `rea-agents`），把「逆向下手」的整条能力接给 AI agent；分析跑在你自己这台机器上，每条结论都带着证据和局限。本册子用一个开源项目做例子，带你从零认识它，并动手跑通两条「不需要额外引擎」的实战。
